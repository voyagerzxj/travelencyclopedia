# 柬埔寨（Cambodia）

> Geography Now 视频 #45 · 发布于 2015-10-10 · [观看视频](https://www.youtube.com/watch?v=wufWxldBWsU)
> 这集在主持人父母家的地下室拍摄，音质不好，主持人说"又回到了阿富汗那集的水平"。这是第一个 C 开头的国家。主持人说柬埔寨本来过得还算正常，直到"4年非常糟糕的日子毁了一切"。

## 国旗
- **上下两条蓝带，中间一条红带**，红带中间是白色的**吴哥窟**图案，吴哥窟是柬埔寨的标志。
  - **蓝色**：传统的王室颜色。
  - **红色**：柬埔寨人民。
  - **白色的吴哥窟**：柬埔寨的精神信仰，这是一个佛教为主的国家。
- 这其实是**1948年最初的国旗**。中间经历了一系列动荡，换了好几面国旗，最后又改回这一面。

## 政治地理
- **位置**：东南亚，西邻泰国，北邻老挝，东邻越南，南临泰国湾。
- **区划**：全国分25个省。
- **首都金边（Phnom Penh）**：
  - 主持人纠正读音为"Pa-Nom Pen"。旧称 Chaktomuk（四面河）。
  - 位置很便利：湄公河、下湄公河、巴萨河和洞里萨河在这里汇合。
  - 王室住在金边。城里摩托车和自行车满街跑，没有停车标志，交通"各凭本事"。
- **岛屿**：
  - 不算小礁石，柬埔寨拥有80多个主要岛屿，大多离岸很近、交通方便，有的从海滩上就能看到，比如从名字很有意思的"夏威夷海滩"能看到蛇岛。
  - 最远的岛、也是柬埔寨最南端的是 **威岛（Koh Poulo Wai）**，原来只用作军事基地，现在对游客开放。
- **跨湄公河大桥**：
  - 长期以来，国家被湄公河分成东西两半，只能坐渡轮或坐飞机过去。
  - **2001年**第一座跨湄公河大桥 **绊桥（Kizuna Bridge）**通车，由日本政府出资，东西两部分首次通过公路连起来。之后又建了3座，还有更多计划中。
- **吴哥窟**：
  - 说起柬埔寨，大家首先想到的就是吴哥窟，**高棉帝国**的古迹。
  - 附近的**暹粒（Siem Reap）**有国际机场，可以直接飞过去。不建议先到金边再坐长途车，因为农村地区"有点不太平"。
  - 吴哥窟除了树木从塔里长出来的迷人景象，还有笔直几何形状的护城河和水库，是帝国为灌溉而巧妙修建的，养活了一整座城市。据推测，那是当时**亚洲最大的前工业化大都市**。
- **农村**：大多数村庄的生活方式高度依赖环境，处于亚热带发展中的状态。

## 自然地理
- **地形**：中部是低平平原，西南部和东部靠越南边境的地方多丘陵和低山。
- **河流**：河流遍布全国。
- **洞里萨湖（Tonlé Sap）**：
  - 在中部偏北，是**东南亚最大的淡水湖**，雨季会大幅扩张。
  - 生物多样性极高，有200多种淡水鱼，比如国鱼**巨型暹罗鲤（Giant Barb）**，最长可达3米。主持人模仿柬埔寨向日本叫板："你们那黄鳍金枪鱼算什么！"
- **大米**：世界大米大会连续三年把柬埔寨评为**世界最好的大米**（原话如此）。原因之一是，和很多第三世界国家一样，大多数人买不起农药，农产品大多新鲜有机。
- **吃昆虫**：鱼是主要的蛋白质来源，但多数柬埔寨人也**吃昆虫**。昆虫营养丰富，低脂低碳水、高蛋白，同样重量的价格只有牛肉、鸡肉的零头。
- **经济**：
  - 虽然食物新鲜，经济其实更依赖**纺织品和鞋类**，"看看你衬衫的标签，说不定就是柬埔寨产的"，还有旅游业。
  - 主持人用美国中西部口音演了一段谐音梗：Angkor **Wat** 和 **what**（"什么？"）。
- **大象**：柬埔寨仍保留和维护亚洲象保护区。在一些地方大象几乎受人敬重，饲养员把它们当作生计来源悉心照料，尤其是游客想骑大象的时候。
- **地雷**：
  - 联合国教科文组织（原话如此）把柬埔寨列为**世界上地雷第三多的国家**，约有400万颗地雷待清除。
  - 因此柬埔寨**人均截肢比例世界最高**，每月有300到700例新的地雷截肢。
  - 国家正在慢慢解决这个问题，但偏远农村地区仍有潜在危险。

## 人口
- **称呼**：
  - 叫"Cambodian"完全可以，但民族的正确称呼是**高棉（Khmer）**。
  - 主持人纠正读音为"Kuh-Mai"，r 不发音。
  - 柬埔寨语叫高棉语，文字、文化也都叫高棉。
- **语言互通**：
  - 说高棉语的人能听懂一点泰语和老挝语，几百年来几种语言互相影响。认真听的话大约能懂四分之一到三分之一。
  - 主持人说泰语和老挝语是声调语言，高棉语不是，所以交流时有点像"对暗号"。
  - 越南语对他们来说完全听不懂。
- **人口**：约**1550万**（2015年）。
  - 约90%是高棉族，约5%越南人，1%华人，其余是其他民族。
  - 约95%信奉**上座部佛教**，伊斯兰教和基督教各约2%，其余1%是其他信仰。
- **一句话历史**：王国、保护国、被占领、王国、共和国、非常糟糕的独裁、越南傀儡、过渡国家，最后又回到君主制。
- **红色高棉**：
  - "非常糟糕的独裁"就是共产党**红色高棉**。70年代掌权后杀害了柬埔寨约**五分之一的人口**，约150万到300万人。
  - 受害者主要是被视为政权威胁的知识分子，以及神父和僧侣。**波尔布特**受马克思主义影响，强制推行世俗化，取缔一切宗教，焚书，洗劫寺庙和教堂。
  - 这解释了为什么如今约一半人口在15岁以下（原话如此）：大屠杀切断了整整一代人，幸存者几十年里又生了大量孩子。
- **国王**：柬埔寨国王是亚洲唯一有部分法国血统的君主，也是亚洲唯一能流利说**捷克语**的君主。现任国王西哈莫尼曾在捷克留学。
- **文化**：深受上座部佛教和传统高棉仪式的影响。
- **贫困与"即兴谋生"**：
  - 作为发展中国家，柬埔寨人平均每天收入约2.6美元。
  - 和东南亚很多国家一样，柬埔寨人是"即兴谋生"的高手。经济基本不受监管，赚钱几乎没有限制，干什么都行。
  - 比如开一个街角加油站，只要一个铁桶加一台空压机，甚至可以用旧汽水瓶卖汽油。主持人插了一句：他在中西部长大，管汽水叫"pop"，坚决不叫"soda"。
- **人口贩卖**：坏处是也给地下腐败产业开了门。柬埔寨的**人口贩卖率**是世界最高之一，包括贩卖儿童。主持人说这很可悲，但必须正视，不能一笔带过。
- **节俭与重建**：柬埔寨人虽然要拼命谋生，却出奇地节俭。君主制恢复后，政府鼓励人们搬回废弃的城镇，免费提供房屋，很多人用来开杂货店、餐馆、摩托修理铺等小生意。

## 朋友圈（外交关系）
- **"差劲的室友"**：主持人问，你有没有过一个朋友，你后来发现他会是个很糟糕的室友？柬埔寨就曾陷入这种处境。如今各方关系大体都还可以。
- **泰国**：
  - 历史上是柬埔寨的宿敌，多次征服想统治整个地区。
  - 至今在**柏威夏（Preah Vihear）**一带仍有争议。
  - 约10年前一位泰国女演员声称吴哥窟属于泰国，引发骚乱，国旗和使馆被烧。
- **越南**：像"别有用心的朋友"，嘴上说"我保护你，作为回报我就控制你一下，可以吧？"
- **法国**：
  - 至今关系不错，有双边协议和使馆，还帮助国内发展。很多学校和大学由法国资助，用法语教学。
  - 由于旅游业，柬埔寨人现在更倾向于学英语作第二语言，但法语仍然在教。
- **最好的朋友：中国、日本、韩国**：
  - 三国对柬埔寨基础设施投资最多，帮忙修路、建楼、建商场和商业中心。
  - 大批韩国人和日本人常来度假，受到热烈欢迎。

## 总结
- 柬埔寨是一个鲜活多彩的国家，70年代肚子上挨了狠狠一拳，但还没认输，正缓过气来、准备迎接下一回合。
