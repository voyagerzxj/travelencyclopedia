# 捷克（Czech Republic / Czechia）

> Geography Now 视频 #75 · 发布于 2016-06-01 · [观看视频](https://www.youtube.com/watch?v=-kaF6SnSEo8)
> 开场：有人问主持人记不记得捷克斯洛伐克，另一个人说"捷克什么？"。这是 C 开头的最后一个国家。捷克当时刚把英文简称改为 **Czechia**。
> 主持人接着玩了一串谐音梗，把 Czech 和车臣（Chechnya）、克罗地亚国旗上的棋盘格（checky）、跳棋（checkers）、国际象棋、汉堡店 Checkers、酒店登记（check-in）搞混，最后说"好吧，开始节目"。

## 政治地理
- **欧洲的心脏**：捷克被称为中欧的心脏，是东西方之间的桥梁。
- **位置**：中欧内陆国，被德国、波兰、斯洛伐克和奥地利包围。
- **区划与首都**：全国分13个州，首都**布拉格**位于西半部中央。
- **三大历史地区**：捷克的地区意识很强。
  - **波希米亚**：你听到的 "Bohemia/Bohemian"，不管指斯拉夫地理区域还是一群人，指的都是捷克这一带。但千万别把整个国家叫波希米亚，那会惹恼全国的东半部。
  - **摩拉维亚**：东部。
  - **西里西亚**：东北角的一小块，有点自己走开、更关注波兰而不是捷克。
  - 三个地区之间有点竞争，没有清晰的分界线，大体上波希米亚在西、摩拉维亚在东，捷克的西里西亚部分在东北角。
- **别叫它东欧**：捷克属于**中欧**，不要说它是东欧国家。
- **汉堡港的租借地**：
  - 捷克基本没有境外领土，不过租用了德国**汉堡港**的几块港区。
  - 这些港区不算飞地，而是作为内陆国捷克的自由贸易港使用。
  - 节目说这些港区将在**2028年**归还德国。
- **叫法**：主持人声明，本集会混用 Czechia 和 Czech Republic 两种叫法，"就像猜谜游戏，你永远不知道我下一个说哪个"。
- **城市**：第二、第三大城市**布尔诺**和**俄斯特拉发**分别在摩拉维亚和西里西亚。它们和布拉格之间的竞争很激烈，"友好，但是'别惹我我就不捅你'的那种友好"。
- **没有郊区**：捷克基本没有郊区，城市一结束马上就是乡村。

## 自然地理
- **森林不多**：
  - 捷克不算欧洲森林最多的国家，城市以外的土地大多是形状不规则的农田。
  - 全国只有4个国家公园，但"有的那几处都做到了极致"。
  - 电影《纳尼亚传奇》的部分场景在这里拍摄。
- **地形像一只碗**：
  - 从太空看，整个国家像一只碗，四周被山包围。
  - 所以它是多条河流的天然汇水盆地，比如**易北河（Labe）、伏尔塔瓦河、摩拉瓦河**。
  - 靠近边界的地方是起伏的绿色丘陵和低山，点缀着森林，山顶上常有古典的波希米亚和摩拉维亚城堡。
  - 还有一片很小的"沙漠"，宽度只有约一公里。
  - 其余大多比较平坦，种满大麦和小麦。
- **啤酒**：
  - 大麦和小麦能做面包和麦片，但更重要的用途是捷克最重要的产品——**啤酒**。
  - 捷克人对啤酒非常认真。主持人说，你以为德国人和爱尔兰人啤酒文化重，那是你还没见过"Czech mate"（谐音国际象棋的 checkmate）。
  - 捷克是**世界人均啤酒消费最高的国家**，每人每年约145升。
- **零容忍酒驾**：酒驾是重罪，处罚极重，几乎零容忍。主持人开玩笑："在捷克，把醉酒打架和精神崩溃留在该留的地方——家里，和家人在一起。"
- **采蘑菇**：说到家人，捷克家庭很爱一起去"**采蘑菇**"，徒步时采野生可食用蘑菇，带回家做菜。
- **经济**：以工业和制造业为主，尤其是汽车业。**汽车生产约占出口的18%**，全国有大量从业人员。

## 人口
- **后共产主义国家里的优等生**：捷克是欧洲后共产主义国家中最稳定、最繁荣的。
- **人口与就业**：约**1050万**（2016年），失业率是**欧盟最低**。
- **民族构成的搞笑之处**：
  - 按任何合理统计，90%以上的人是捷克族，但只有约65%的人明确填了"捷克族"，约25%是"未申报"。
  - 原因是人口普查里"民族"一栏是选填，很多人直接跳过了。
  - 其余的人自认是摩拉维亚人、斯洛伐克人或其他民族。其他民族里最大的是乌克兰人，出人意料的是还有**越南人**。主持人说："看来捷克是越南人的热门目的地，谁能想到呢？"
- **语言**：
  - 官方语言是**捷克语**，一种斯拉夫语，和斯洛伐克语能互通，和波兰语有点差别但也能大致听懂。
  - 捷克语是唯一使用字母 **Ř/ř** 的语言，这个音是卷舌颤音加擦音，很难发。一位捷克人在节目里做了示范：比如"河"（řeka）。
- **建筑**：捷克真正与众不同的是它独特的建筑，融合了古典**巴洛克**和**哥特**元素，门厅和走廊装饰着华丽的柱廊。
- **文化名人**：出过很多世界知名的作曲家、艺术家，还有1位诺贝尔文学奖得主（塞弗尔特）。
- **历史一句话版**：和欧洲几乎每个国家一样，捷克经历过复杂的王国、帝国、公国、宗教改革、联盟、战争、联合、革命、分裂，还当过一段时间东方阵营的一员。但不管经历什么，他们一直保留着独特的中欧斯拉夫民族认同。
- 节目里还放了捷克体育迷欢呼、吹号的片段。

## 朋友圈（外交关系）
- **奥地利和匈牙利**：作为前奥匈帝国的一部分，捷克即使在20世纪初帝国解体后，仍和奥地利、匈牙利关系密切。
- **列支敦士登**：因为过去在当地拥有的城堡和土地问题，列支敦士登和捷克有过纠纷，甚至很长时间不承认捷克，直到**2009年**才说"唉，好吧，随便"，正式建交。
- **维谢格拉德集团**：总体上和波兰、斯洛伐克、匈牙利是好朋友，彼此在商业和政府合作上都很好。
- **最好的朋友：斯洛伐克**：
  - 毫无疑问。两国不只是朋友，更像90年代被分开的连体双胞胎。
  - 那是**最和平的一次分裂**（1993年"天鹅绒分离"），至今捷克人和斯洛伐克人始终手牵着手。

## 总结
捷克就像斯拉夫家族里那个长大成人、找到工作，只在非去不可时才勉强出席家庭聚会的兄弟。下一集：丹麦。
