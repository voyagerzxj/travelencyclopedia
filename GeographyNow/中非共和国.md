# 中非共和国（Central African Republic）

> Geography Now 视频 #52 · 发布于 2015-12-22 · [观看视频](https://www.youtube.com/watch?v=r4KyslvtOk4)
> 开场：在这儿迷路的话，指南针是你最不想用的东西，原因见"自然地理"。本集简称这个国家为"共和国"。

## 国旗
- **蓝、白、绿、黄四条横带**，中间一条**红色竖带**把旗面一分为二，左上角有一颗**黄星**。
- **设计用意**：融合法国三色旗和泛非颜色，红色两边都有。
- **按官方解释**：
  - 蓝色：天空与自由
  - 白色：和平与尊严
  - 绿色：希望与信仰
  - 黄色：宽容
  - 红色：（又是）为国家流的血
  - 黄星：通往自由和解放的指引
- 这个国家曾有一段非常混乱的时期用过另一面国旗，中非人大多不愿提起，下文会讲到。

## 政治地理
- **一把双刃剑**：这是地球上既受眷顾又受诅咒的地方之一。
- **位置**：中部非洲，与6国接壤（别忘了苏丹分成了两个）。约三分之二国土在**乌班吉河流域**。
- **其实不在非洲正中心**：非洲地理中心在刚果（布）的 Dongou 镇附近。主持人替它叹气："差一点！"
- **行政区划**：
  - 全国分**16个省（prefecture）和1个自治市**，自治市就是首都**班吉（Bangui）**。
  - 其中 Nana-Grébizi 和 Sangha-Mbaéré 两个是"经济省"，负责管理和促进国家的经济活动。
  - 各省大多以流经的河流命名，这些河最后不是流进刚果河就是流进乍得湖。
- **布阿尔巨石阵**：在 Nana-Mambéré 省，是新石器时代的巨石群，有时被称作"非洲的巨石阵"。
- **形状像布基纳法索**：西北都有一个隆起，西边都有一个"鼻子"，主持人说像"出生时（或者去殖民化时）失散的双胞胎"。
- **首都班吉**：在最南端的乌班吉河边，紧挨刚果（金）边境。大多数人住在西部或班吉周边，北部人烟稀少。
- **交通很差**：
  - 历史上出行一直困难，连法国殖民者都不太愿意深入内陆。
  - 人口超过两三万的城市只有约17个（原话如此），大多在西部。其余的人住在零散的村子里，一个村子只有几百人。
  - **铺装道路不到8%**，很多偏远地区与邻镇几乎不通。河流提供船运，但完全与世隔绝也不少见。

## 自然地理
- **未开发的资源宝库**：人口稀少、交通不便、政府控制力弱，所以国土大多被森林覆盖，未经开发，有好有坏。主持人边"咳嗽"边说"这也是约瑟夫·科尼的军队绝佳的藏身处"，然后改口"我没有支气管炎"。
- **地形**：北部是平坦的稀树草原，中部是赤道森林和起伏的丘陵，南部是茂密的丛林。
- **河流**：主要河流有30多条，最美的景点之一是班吉附近的**博阿利瀑布（Les Chutes de Boali）**。
- **植物**：已记录约3600种，推测可能有约5000种，很多是当地特有种。
- **桑加国家公园（Dzanga-Sangha）**：在全国最南端，有密度最高的珍稀野生动物，比如条纹漂亮的**紫羚（Bongo）**。中非共和国的**西部低地大猩猩和森林象**密度是非洲最高的。
- **观星胜地**：中非共和国是**世界上光污染最少的国家**，晴朗无月的夜晚，肉眼就能看到银河。
- **农业**：雇用了约70%的人口，种山药、木薯、花生、高粱等。主持人顺便告诉"雅皮士"们，高粱不含麸质。
- **班吉磁异常**：
  - 在这里指南针会乱转，因为全国正好处在非洲最大的**磁异常区**中心。磁异常指地球磁场出现奇怪变化的地区。
  - 世界最大的磁异常在俄罗斯**库尔斯克**，原因很好解释：地表附近有巨大的铁矿。
  - 班吉磁异常的成因至今说不清：有人认为地壳下有大量火成岩，也有人认为是很久以前的陨石撞击。
  - 如果真是陨石，也许能解释地下矿物和矿石的挤压与分布。
- **钻石**：
  - 出口收入约一半来自**钻石**，其次是贵金属。主持人又顺口玩了个"像钻石一样闪耀"的梗，抱怨蕾哈娜不理他。
  - 可惜采矿业很不发达，潜力巨大却开发不多，部分原因是这个国家治理一直很糟糕。

## 人口
- **称呼**：这里的人叫"**中非人**（Central African）"，不是"中非共和党人（Central African Republican）"。
- **人口**：约**470万**（2015年），大约是独立时的4倍。
- **民族**：
  - 约80个部落，各有语言和方言，但大体出自三大母群。
  - 最大的是**巴雅-曼加人（Gbaya/Mandjia）、班达人（Banda）、姆巴卡人（M'Baka）**，合计超过90%。
  - 另有其他非洲部落，以及少数白人，多为法国或比利时后裔。
- **语言**：
  - 法语是官方语言，但说**桑戈语（Sango）**的人更多，桑戈语也是官方语言。
  - 别的非洲国家大多是在欧洲语言基础上形成克里奥尔语，桑戈语却是少数**以非洲语言为基础的非洲克里奥尔语**之一，以当地的 Ngbandi 语为基础。
  - 殖民前和殖民期间就被广泛用于部落间交流，至今大多数中非人都会说。
- **"太黑暗了不想听"？**：主持人模仿观众抱怨"我们只想听美好的事！"，回答"那你不属于这个星球"。
- **贫困**：
  - 世界最穷的国家之一，常年排在倒数10名以内。人均 GDP 约350美元/年。
  - 这个数字可能不准，因为只统计有申报的交易。丛林肉、传统药材、象牙、自产作物等大量未登记的地下交易都没算进去。
- **政变频繁**：独立以来发生过很多次政变，是非洲最多的国家之一，但不是世界最多。主持人说"那个国家我们很快就会做到"，下一集智利会讲。
  - 主持人比喻这里像一场"大逃杀"：人人想夺权，可一旦掌权，处境比没权时还危险。
- **博卡萨（Bokassa）**：
  - 60年代末到70年代最混乱。博卡萨推翻了自己的表亲，自封为"中非皇帝"。
  - 加冕典礼花掉了国家预算的近三分之一，**皇冠就值500万美元**。
  - 他主持司法殴打、处决和屠杀，包括杀害拒绝从他一位妻子的公司买校服的学生。
  - 最终在法国伞兵帮助下被推翻，国家恢复共和制。后来又乱，又打内战，留下一个烂摊子，至今仍在恢复。
- **主持人的比喻**：就像一个孩子走进食堂摔了一跤，餐盘洒了一地，周围的人盯着他，几秒钟就决定了怎么评判他。

## 朋友圈（外交关系）
- **欧洲**：最大的进口来源是荷兰，最大的出口对象是**比利时**，比利时人爱钻石，在资源开采上投了很多钱。
- **法国**：仍然亲近，但更偏向撒哈拉以南其他法语国家。科特迪瓦、塞内加尔等更受关注，中非共和国有点觉得被冷落。
- **韩国**：意外的老朋友，独立后3年就建交，至今是中非共和国最大的亚洲进口来源。
- **最好的朋友：喀麦隆**：
  - 主持人唱"人人都爱喀麦隆！"
  - 大多数人住在靠近喀麦隆的西部，文化上认同喀麦隆人。
  - 喀麦隆还给中非共和国提供出海口，大部分进出口经杜阿拉港。

## 总结
- 坐在一座钻石矿上也没用，除非你把立法和治理搞好。主持人说希望中非共和国能做到。
