# 加拿大（Canada）

> Geography Now 视频 #48 · 发布于 2015-11-10 · [观看视频](https://www.youtube.com/watch?v=SxhUsPBFPkU)
> 有40多位加拿大观众发邮件帮忙做这集。开场玩笑：美国人像十几岁的男孩，有主见、精力旺盛、自信；加拿大人像十几岁的女孩，当面客客气气，背后说你坏话。

## 国旗
- **红底，中间一块白色方块，正中是一片11个尖角的红色枫叶**。
  - **红色**：两次世界大战中的牺牲。
  - **白色**：国家的和平、安宁与中立。
  - **枫叶**：几百年来，甚至英国统治时期，一直是加拿大的象征。
- **11个尖角**：有人说代表各省和领地，其实不是，枫叶本来就长这样。
- **魁北克**：更愿意挂自己的鸢尾花旗，而不是枫叶旗。

## 政治地理
- **面积**：加拿大是世界第二大国家，行政区划自然有不少有趣之处。
- **位置**：北美洲，美国以北，东、北、西三面分别是大西洋、北冰洋和太平洋。
- **时区与区划**：
  - 横跨6个时区。
  - 分为10个省和北部3个领地。纽芬兰和拉布拉多合起来是一个省。
  - 首都**渥太华**在安大略省。
- **美加边界**：
  - 全长8800多公里，沿途有几千个界标，是**世界上最长的两国边界**。
  - **东海岸**还算平静，只有两处小插曲：与丹麦有争议的一个岛（汉斯岛），以及皮划艇就能到、法国死活不放手的那块地（圣皮埃尔和密克隆）。
  - **德比莱恩与斯坦斯特德（Derby Line / Stanstead）**：
    - 到了魁北克和佛蒙特交界处就乱了。这个镇建在现代边界划定之前，很多房屋、商店和建筑正好压在边界线上。
    - **哈斯克尔免费图书馆**在阅览室地板上标出了国界，两国的人各走自己一侧的入口。从另一国出来的话，必须走人行道去海关报到，踏上马路可能被捕。
  - **西北角（Northwest Angle）**：
    - 一块"意外"划出来的明尼苏达州领土，大部分归奥吉布瓦部落所有，位于伍兹湖上。
    - 那里有两个度假胜地，名字叫"大屠杀岛"和"小屠杀岛"，主持人说名字"让人放心"。
  - **北纬49度线**：其余边界尽量沿北纬49度线直行，但也有点弯弯曲曲。有4个机场的跑道跨在边界上，或者和边界完全平行。
- **人口集中在南部**：约80%的加拿大人住在离美国边界160公里（100英里）以内，越往北越"模糊、被忽视"，越难融入国家其他部分。
- **北部交通**：
  - 从南方通往育空和西北地区的主要公路只有两条。
  - 从任何省或领地都几乎没有路通往**努纳武特**，只能坐飞机或坐船。主持人说技术上也可以走过去，"但那会很惨"。
- **阿勒特（Alert）**：在努纳武特，是世界上**最北的有人居住地**，常年冰冻荒凉，平时只有5个人左右驻守，既是军事站也是季节性科研站。
- **魁北克**：加拿大各个行政区在宪法上都能拼在一起，直到魁北克。魁北克仍是加拿大的一个省，但有强烈的魁北克民族主义，不少人甚至走向分离主义。

## 自然地理
- **"伟大的白色北方"**：但并不是所有地方都是冰冷的北极苔原，地质和气象（主持人得意地念出 meteorological 这个词）共同塑造了地貌。
- **哈德逊湾**：
  - 世界第二大海湾，仅次于孟加拉湾，也是冬季会封冻的最大海湾。
  - 它的流域几乎滋养了半个加拿大，还包括美国西北的一小部分（原话如此）。
  - 湾区有一个**重力异常**：这里的重力比地球平均值略低，跟地幔对流和冰川融化后的地壳回弹有关。
  - 主持人做了个"哈德逊90X减肥法"的假广告：去哈德逊湾就能减重。
  - 不过湾边几乎没人住：岩石崎岖、坑洼不平，池塘湖泊太多，修不了直路。
- **湖泊与淡水**：
  - 加拿大约有200万到300万个湖泊，据推测**世界上约60%的湖泊、约30%的淡水**都在加拿大（原话如此）。
  - 加拿大的自来水甚至可能比瓶装水质量更好。
- **加拿大地盾**：
  - 这主要归功于占国土约一半的**加拿大地盾**：一片裸露的前寒武纪火成岩高原，土壤和植被很少，却是采矿的宝地。
  - 加拿大有世界上最富的镍、金、银、铜等金属矿藏。
  - **世界上约三分之二的铯来自马尼托巴省的一座矿（Bernic Lake）**。
- **世界最大的"三级湖中岛"**：
  - 在**维多利亚岛**上，是岛上湖中的岛里的湖里的岛（原话说"湖中岛上的湖中岛"）。
  - 这块约4英亩的弯曲岩石是几年前地图迷在谷歌地图上发现的，没有名字，很可能从没人踏足过。
  - 主持人说愿意去，但需要企业赞助，"我说的就是你，Aunt Jemima（美国枫糖浆品牌）"。
- **陨石坑**：地球十大撞击坑里加拿大有两个，安大略的**萨德伯里陨石坑**和魁北克的**马尼夸根陨石坑**。后者是近乎正圆的环形，现在是个水库，从太空都能看到。
- **快速冷知识**：
  - 约40%国土是森林，世界森林的约十分之一在加拿大。
  - **世界60%以上的北极熊**生活在加拿大。
  - **芬迪湾**有世界最大潮差，最高超过16米。
  - 尼亚加拉瀑布很壮观。
  - **托尔峰（Mount Thor）**有世界上最高的垂直落差。
  - **魁北克一个省就供应了世界约70%的枫糖浆**，还有一个存着22.2万多桶枫糖浆的**枫糖浆战略储备库**。
  - **爱德华王子岛**有一种奇怪的现象，海滩上的沙子踩上去会吱吱响。
  - 除了与美国共有的五大湖，最大的内陆湖是**大熊湖**和**大奴湖**。大奴湖得名于 Slavey 原住民，主持人强调"不是奴隶（slave），是 Slavey 人"。

## 人口
- **人口**：约**3500万**（2015年），是世界上人口密度最低的国家之一。
  - 约四分之三是白人，亚裔约14%，原住民约5%，黑人约3%，拉丁裔约2%，其余是其他群体。
- **法语社群**：
  - 除了族裔，加拿大还按语言分群体：**每三个加拿大人中就有一个**会说法语或能听懂够用的法语。
  - 魁北克问题在加拿大社会运作中至关重要，国家得非常努力才能让这个省配合。
  - 法语不只在魁北克说。安大略、马尼托巴，尤其是纽芬兰、新不伦瑞克、新斯科舍等沿海省份都有大量说法语的社区，他们的文化区隔更深。
  - 很多沿海省份的人有独特的**阿卡迪亚法语文化**，和魁北克不同。
- **卡津人的来历**：
  - 美国路易斯安那的卡津人（Cajun）大多是阿卡迪亚人的后代，18世纪被英国人从这些省份驱逐流放到那里。
  - 那时还没有路易斯安那购地案，那片土地还属于法国。后来他们发明了秋葵汤。
  - 主持人对美国人喊："所以卡津人说法语，美国！就是因为加拿大！"
- **移民**：约五分之一的加拿大人在国外出生，所以加拿大相当多元。主持人顺便讽刺了美国影视剧"凑多元化配额"的套路。
- **北部三领地聚光灯**：
  - 多伦多、温哥华、卡尔加里常被关注，北部三个领地（育空、西北地区、努纳武特）却没人给机会。
  - 三地合计只有约11万人，是全国人口最稀疏的地区。
- **原住民**：
  - 加拿大原住民约85万人，全国有约630个保留地，最大的几个在北部领地。
  - 分三大类：**第一民族（First Nations）**，大多是住在森林地区的南方部落；**梅蒂人（Métis）**，原住民混血；**因纽特人（Inuit）**，北极居民。
- **三个领地的区别**：
  - **育空**：以白人为主。
  - **西北地区**：第一民族部落多，比如大奴湖附近的 Slavey 人，很多人更喜欢被称为 **Dene 人**。美国的纳瓦霍人一定程度上可追溯到他们。主持人喊："看，一切都是相连的！"
  - **努纳武特**：几乎全是因纽特人。它原本和西北地区是同一个领地，**1999年**分出来独立成为领地。
- **因纽特文化**：
  - 主持人说因纽特文化是最被低估、也最迷人的文化之一。
  - 他们说**因纽特语（Inuktitut）**，和格陵兰语是近亲，基本能互通。
  - 有自己的书写文字，路牌和交通标志上都能看到。
  - 有丰富的传统、仪式、游戏、音乐和饮食。主持人建议去了一定尝尝**鲸脂**，看看**喉音游戏歌**的表演。

## 朋友圈（外交关系）
- **一句话**：主持人开玩笑说"加拿大跟所有人都是朋友，完"，然后又展开讲了一点。
- **外交风格**：
  - 加拿大的外交政策鼓励和几乎所有能结交的国家往来。美国对古巴禁运后，加拿大仍和古巴关系很好。
  - 不过它的关系网常和美国同步，美国的盟友就是它的盟友，美国的对手就是它的对手。主持人问："你看过电影《逃离德黑兰》吗？"
- **英联邦**：加拿大不仅是英联邦成员，还是**英联邦王国**（两者有区别），所以和前大英帝国各地基本都处得来。法语国家也和加拿大很合得来。
- **墨西哥**：有意思的是，美国抱怨墨西哥移民，加拿大却在积极吸引墨西哥人。加拿大出生率低、需要劳动力来照顾老龄人口，于是放宽了移民和签证政策，吸引中美洲的技术工人，在墨西哥到处发广告传单。
- **最好的朋友：美国**：
  - 有人说加拿大像美国的小弟，有人说是最好的朋友。主持人认为两国更像**高中时的初恋情侣**，从一开始就彼此相伴。
  - 美国是加拿大最大的出口和商业伙伴，两国在国家层面和军事上关系最紧密。
- **加美的区别**：
  - 美国靠武力赢得独立，加拿大靠外交。
  - 美国的移民政策像"大熔炉"，期望人们同化；加拿大像"马赛克"，鼓励保留各自的文化特色。
  - 主持人总结：两国就像一对可爱的高中情侣，有时互相取笑，但说到底就是在交往，还在电影院后排亲热。
