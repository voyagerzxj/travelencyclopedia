# 玻利维亚（Bolivia）

> Geography Now 视频 #33 · 发布于 2015-07-01 · [观看视频](https://www.youtube.com/watch?v=AJx1RcIO61I)
> 主持人几年前去过玻利维亚，这集用了不少他用2010年的旧摄像机拍的素材。

## 国旗
- **红、黄、绿三色横条**，中间是国徽：
  - **红色**："跟我一起说"，为国家战斗者的鲜血。
  - **黄色**：资源财富。
  - **绿色**：自然的丰饶和希望。
- **国徽**：
  - 中间画着日出下的**波托西山（Potosí）**，还有羊驼、棕榈树和一捆麦子，代表国家资源。
  - 周围蓝框上有**10颗星**：9颗代表9个省，第10颗代表19世纪被智利夺走的**滨海省（Litoral）**。
  - 两侧各有三面玻利维亚小国旗，所以玻利维亚也是"国旗上有自己国旗"的国家之一。
  - 后面是4支火枪，前面是2门大炮，代表独立斗争。炮上有弗里吉亚帽和斧头，代表自由。
  - 顶上是一只**安第斯神鹫**和月桂枝，代表和平与保卫国家的决心。
- **维帕拉旗（Wiphala）**：彩色方格旗，在玻利维亚随处可见，也是国家象征，尤其代表原住民，特别是艾马拉人。
- 主持人宣布：玻利维亚超过伯利兹，成为节目里讲过的最复杂的国旗。

## 政治地理
- **位置**：南美洲内陆国，与秘鲁、巴西、巴拉圭、阿根廷、智利5国接壤。
- **边界勘测得非常精细**，因为它和每个邻国都打过仗，"连小小的巴拉圭也是，尤其是巴拉圭"。
- **失去的领土**：
  - 过去国土比现在大得多，曾有出海口**滨海省**。
  - 后来智利拿走了滨海省，巴西拿走一部分，巴拉圭拿走一部分。
- **9个省，两个首都**：
  - **苏克雷（Sucre，意为"糖"）**：宪法首都，最高法院所在地。
  - **拉巴斯（La Paz）**：正式名称意为"和平圣母"，是政府所在地，立法和行政机构都在这里，总统住在 Palacio Quemado（"烧毁宫"）。
- **拉巴斯：世界最高的首都**：
  - 海拔约3700米（12000英尺）。主持人说"自从中国接管西藏后"它就成了最高首都。
  - 游客常会呼吸困难、出现高原反应，当地人会给你**古柯叶**（coca，不是可可 cocoa），泡茶喝或直接嚼。
  - 水在约88°C就沸腾，做饭要更久。
  - 气压太低，很多等离子电视都没法正常工作。主持人说："学化学，以后再说。"
  - 城市被雪山 **伊伊马尼山（Illimani）**俯瞰，高楼和纪念碑很多。
- **离开拉巴斯很难**：
  - 往西要穿过世界上最干燥的**阿塔卡马沙漠**，有些地方看起来和月球一样。
  - 往东要翻越安第斯山，高到能看见脚下的云，一路下到亚马孙热带盆地。
  - 往东先得走**云加斯公路（Yungas Road），即"死亡之路"**：最窄处只有约3米宽，紧贴600多米深的悬崖，没有护栏，却是双向车道，每隔几百米有可以错车的弯道。每年约200到300人死于这条路。它反而成了热门旅游项目。

## 自然地理
- **反差极大**：
  - 西部约三分之一是干燥多石、积雪覆盖的安第斯山。
  - 翻过山往东是湿热的潘帕斯和雨林。
- **南美人口最稀疏的国家**：内陆大多未经开发。花约70美元就能参加三天的生态游，有小屋和饭菜，可以钓食人鱼、喂野猴、看鳄鱼、和**粉红河豚**一起游泳。主持人感叹"汇率就是这么好"。
- **乌尤尼盐沼（Salar de Uyuni）**：
  - 在南部波托西省，**世界最大的盐沼**。
  - 旱季是一望无际的平坦白色盐床。
  - 雨季覆上一层浅水，成了"**世界上最大的镜子**"，人可以在上面走。
- **的的喀喀湖（Titicaca）**：
  - 靠近拉巴斯，号称**世界最高的湖**（原话如此，实为最高的可通航大湖），与秘鲁共有。
  - 玻利维亚没有海岸线，却**有海军**，主要在湖上和河上巡逻。
- **农业**：
  - 约占 GDP 的四分之一，但只开垦了约2%的土地，大量可耕地没用起来。
  - 经济作物有咖啡、棉花和**古柯**。古柯叶用得好能治病，用得不好就成了害人的毒品。主持人先开玩笑说是"金马天尼"，然后才说是**可卡因**。
  - 古柯在玻利维亚已种植了几百年，也让它和一些朋友关系紧张。

## 人口
- 约**1050万人**（2015年）。
- **原住民占多数**：
  - 玻利维亚和秘鲁是南美仅有的两个原住民占多数的国家。
  - 玻利维亚是**美洲乃至全世界唯一原住民占一半以上**的国家（原话如此）。
  - 另有约30%梅斯蒂索人、约15%白人。
- **原住民群体**：共约30个，最大的是**克丘亚人、艾马拉人和瓜拉尼人**。
  - 艾马拉人和克丘亚人多住在西部安第斯山区。
  - 瓜拉尼人和其他亚马孙部落多在东部森林。
  - 这三种语言加上西班牙语，是**四种主要官方语言**（实际宪法承认了36种）。
- **玻利维亚西班牙语**：口音受原住民语言影响很重，还有不少独特词汇。主持人举了几个"男人""垃圾""小孩"的不同说法，还演了一段"我没钱"的俚语对话。
- **两大地域群体**（像比利时那样分成两类）：
  - **Colla**：西部安第斯山区的人。
  - **Camba**：东部雨林地区的人。
  - 另有 **Chapaco**，塔里哈（Tarija）一带的人，更认同阿根廷。
  - 两大群体生活环境完全不同，文化差别也很明显。
- **原住民色彩浓厚**：习俗、仪式、服饰和节日受原住民文化影响很大。
- **圆顶礼帽**：农村地区，戴**圆顶小礼帽**的妇女多半是玻利维亚人；秘鲁妇女更常戴宽平檐的帽子。主持人赶紧补充"不是说所有人都这样"。
- **摔跤的 Cholita**：在拉巴斯和埃尔阿尔托可以看到穿传统服装的 cholita（原住民妇女）和男人、和彼此摔跤的表演。

## 朋友圈（外交关系）
- **总态度**："我不喜欢你……大概吧……但还是给你个使馆。"
- **邻国**：除秘鲁外，和邻国关系都有点紧张：
  - 巴拉圭：**查科战争**。
  - 巴西：**阿克里战争**。
  - 智利：**太平洋战争**。
  - 阿根廷：也有过摩擦。
  - 不过这些国家都在玻利维亚设有使馆和领事馆，关系仍相对紧密。
- **以色列**：
  - 总统不太喜欢以色列，还威胁过断交（2009年确实断过交）。
  - 但很多玻利维亚人强烈反对，因为以色列人是游客的一大来源。拉巴斯很多地方有希伯来文路牌和海报，不少当地人还学了希伯来语招呼游客。
- **新朋友：委内瑞拉和古巴**：三国都认同反帝国主义和社会主义理念。主持人说考虑到切·格瓦拉在玻利维亚的下场，这有点讽刺。
- **老朋友：秘鲁**：两国曾短暂组成**秘鲁-玻利维亚邦联**，一起对抗智利。秘鲁出于同情，允许玻利维亚在秘鲁境内建一个出海港口。

## 总结
玻利维亚自称"南美的心脏"，看过它那些惊人的东西，这话并不难信。"他们只是希望自己有片海。"下一集：波斯尼亚和黑塞哥维那。
