# 马里（Mali）

> Geography Now 视频 #276 · 发布于 2018-07-11 · [观看视频](https://www.youtube.com/watch?v=5Twr04-ViR4)
> 开场："如果有一个国家藏着历史上非洲最深的秘密和宝藏，你可能会说'埃及？埃塞俄比亚？'好吧，那些都是候选。但试试这个国家：有史上最富有的人，有在科学、天文和文学上繁荣的城市，还有**黄金**！看来马里登场了！"
>
> "今天的马里和几千年前很不一样，但仍有一群迷人的人把这个快速增长的国家当作家园。我们回到非洲的沙漠吧。"
>
> **说明**：本集涉及马里北部的分离运动和武装冲突，以下按主持人2018年时的说法整理，后续局势见文中括号补充。

## 政治地理
- **国名**："马里"最初来自曼丁卡语里的"**河马**"，后来变成"**国王居住的地方**"之意，"不管哪个，都带着力量的含义"。
- **位置**：马里是西非内陆国，与7国接壤。**本初子午线**在加奥城附近穿过它，"去的话可以同时站在两个半球"。由于边界是直线，它没有单一的最北点或最东点。
- **行政区**：全国分10个大区，首都**巴马科**自成一个区。
- **南北两部分**：
  - 肥沃的萨赫勒西南部，约90%的人住在这里。
  - 干旱的撒哈拉东北部，约占国土的65%。
- **北部冲突**：
  - 北部是紧张局势开始的地方，主要是**图阿雷格族**社群对抗马里中央政府，争取分离出一个他们称为"**阿扎瓦德**"的新的自称独立地区，由**阿扎瓦德民族解放运动（MNLA）**领导。
  - 2012年爆发战斗，马里政府很快重新夺回控制。总理曾访问基达尔的总部寻求谈判，但如今争取自治和民族主义的诉求仍在延续。
  - "这是个棘手的局面，我不粉饰。大多数旅行社至少对这些地区发出某种警告。"Ken："可我想去**廷巴克图**！""你可以，只要谨慎、聪明点。"
- **城市与机场**：
  - 首都巴马科之后最大的城市是**锡卡索**和**莫普提**。
  - 只有一个主要国际机场：巴马科**塞努国际机场**。加奥技术上也有国际机场，但只服务荷兰空军和联合国维和任务航班。廷巴克图、莫普提等地区机场有的停飞，有的服务有限。"很可惜，廷巴克图是那么重要的历史名城。"
- **跨撒哈拉公路**：国土一直延伸到撒哈拉中部，但只有一条跨撒哈拉公路，在 **哈利勒**边境进入阿尔及利亚，阿尔及利亚在自己那侧修了双层围墙。
- **陶代尼盐矿**：廷巴克图地区没有通往北方的公路，那里几乎没人住。不过一些勇敢的游牧民甚至游客会坐车或骑骆驼前往也许是世界上最偏远孤立的据点：**陶代尼**，一座几个世纪以来一直有人开采的著名盐矿。
- **景点**：
  - 巴马科国家博物馆、巴马科市中心市场、手工艺市场、独立纪念碑。
  - 玫瑰沙丘、古伊纳和丹丹瀑布、梅迪纳堡、巴马科大清真寺、国家动物园。
  - 传说中的廷巴克图城里几乎任何东西。
  - **塞古**的陶器、**邦贾加拉**悬崖村落、**阿斯基亚墓**。
  - 全国以多座传统泥砖清真寺和建筑闻名。最有名的大概是最具标志性的地标：**杰内大清真寺**，世界上最大的**泥砖建筑**，1907年建成现在的完整形态，每年在天气侵蚀后翻修一次，还出现在国徽上。
- "不过马里真正的动力源是几乎全国人都依赖的那条生命之河：**尼日尔河**。"

## 自然地理
- **开场小品**："时不时会遇到这种国家：土地很多，但几乎所有人都挤在一小块舒适的城区，很少有人出去。"卡塔尔："哈哈！快到我那集了。""哦又是你？你叫什么来着？Jon？你怎么上节目的？""前几集我都在。""哦对，欢迎加入团队！"
- **西非克拉通**：马里位于所谓的 **西非克拉通**上，"一种地质板块区，研究石头的人大概感兴趣"。
- **三大自然区**：北部炎热干燥的撒哈拉沙漠；中部半干旱的**萨赫勒**稀树草原带；最南部的热带稀树草原和疏林带。
- **最高峰**：最高峰 **洪博里通多山**在中东部的莫普提区。
- **湖泊**：
  - 不远处有个矛头状的裂缝样地方，那是**法吉宾湖**（"所谓的湖"）。它本应是全国最大的湖，在河水泛滥时充当水库，但如今几乎完全干涸，只剩半干旱的湖床。大部分溢出的水改流向它下面的特莱湖、奥罗湖、法蒂湖等小湖。
  - 最大的永久湖泊是南部的**马南塔利湖**，由马南塔利大坝形成的人工湖。
- **尼日尔河**：
  - 说到水，大家只关注一条：**尼日尔河**。整个马里经济几乎都局限在这片河流地区：它流经5个大区，包括北部的廷巴克图和加奥，穿过首都巴马科和每一座重要的商业城市。
  - 再往西是**塞内加尔河**的支流，构成国家的另一条脊梁。也是在这一带，大概能找到国兽**豹**。
  - 南部雨季有时会让尼日尔河泛滥，形成**尼日尔内陆三角洲**：一大片季节性湿地，很像博茨瓦纳那集讲的奥卡万戈三角洲。"季节性河流三角洲泛滥，就像大自然妈妈在皮疹后给皮肤保湿。"
- **Noah 讲经济**：
  - 尽管有水，只有约10%的土地有森林，约6%可耕。主持人说约7%的劳动力从事农业，占 GDP 约42%（原话如此，实际务农人口比例远高于7%）。
  - 不过农作物不是最大的产品，**黄金**和**棉花**才是，两者占出口收入约80%。马里是**非洲第三大黄金生产国**，最赚钱的金矿在东南部的**班布克山**。
- **饮食**：马里有很多不同民族的地方菜，全国知名的有：
  - 马里风味的 **Jollof 饭**（ 西非炒饭）。
  - **Dableni** 果汁（洛神花汁）、花生酱炖肉。
  - 图阿雷格风味的 Alabadia、Fakoye、Saga Saga。
  - 马里茶。
  - **Poulet Yassa**（洋葱柠檬鸡）。"对，Poulet，法语的'鸡'，这透露了一点这些人的背景故事。"

## 人口
- "马里很有意思，它是一个在挣扎的国家，没错，但他们以最多彩、最独特、最热情、最耀眼的方式挣扎，每个地区都有自己的耀眼方式。"
- **基本情况**：
  - 约1800万人，出生率世界第三高，预计到2035年人口翻倍。
  - 人口相当多元。约一半属于更广义的**曼德人**，约16%是各支**富拉尼人**，13%是沃尔特语族群体，约10%主要在北部，是**图阿雷格人**和摩尔人，其余是其他群体，包括相当数量的**桑海人**。
  - 货币**西非法郎**，C 型和 E 型插座，靠右行驶。
- **语言**：作为前法国领地，法语曾在学校教授，如今是官方语言，所有族群都用它互相交流。此外还有13种官方认可的民族语言。（2023年新宪法已将法语降为工作语言。）
- **曼德人与三大帝国**：
  - 布基纳法索和冈比亚那几集提过曼德人，他们是马里最大的群体，是西非三大著名帝国**加纳、马里、桑海**的创建者和维持者的后裔。
  - 加纳："耶！加纳！"主持人："其实加纳帝国离现代加纳很远，和他们没关系。"
- **黄金时代**：
  - 历史上马里在北非萨赫勒王国之间的**跨撒哈拉贸易**中扮演了重要角色。14世纪时，**廷巴克图**和**杰内**是学术、科学、天文和文学的中心。
  - **曼萨·穆萨**可以说是历史上最富有的人，如果不是唯一的话。
  - 直到欧洲人的海上贸易兴起，加上后来的饥荒和摩洛哥人的入侵，这些帝国才开始衰落。
- **富拉尼人**：分布在整个西非，约1/3是牧民，是世界上最大的游牧民族。约250万住在马里，所以马里约5%到10%的人是游牧民。Keith："他们是不是弹那种 Hoddu 吉他的？""是的。""太酷了！"他们以女性的发型、编织帽和宽松多彩的饰品服装闻名。
- **南部群体**：
  - 有沃尔特语族、塞努福人和布瓦人等。Keith："是不是弹那种像木琴的 **Balafon** 的？""是的。""太酷了！！"
  - 还有著名的**多贡人**：他们有世界上最长的宗教仪式 **Sigui 节**，每**60年**举行一次，仪式本身能持续好几年。每年还有一次在圣湖安托戈湖的**捕鱼狂欢**，男人们跳进湖里尽可能多地抓鱼。
- **北部的图阿雷格人**：与北非柏柏尔人有亲缘关系，居住在广袤的撒哈拉。这个民族有几千年前伊斯兰时期的历史和传统，根植于适应沙漠的部落和习俗，"地球上别处找不到"。Keith："他们是不是弹那种 **Imzad**（单弦提琴）的？"主持人："Keith，你今天在乐器探索之旅啊。""我能说什么呢，吉他、乐器，太酷了。"
- **宗教**：
  - 有句话说："马里98%是穆斯林，2%是基督徒，**100%是万物有灵论者**。"就像最近的埃斯瓦蒂尼那集讲的，马里南部大多数人信奉某种宗教多元主义，这里是和伊斯兰教融合。很多人自称穆斯林，大多属**苏菲派**，但融合了传统泛灵信仰，以保持与前伊斯兰根源的联系。
  - 这当然不太被北部信奉逊尼派的图阿雷格人等群体接受，这是国内冲突的主要因素之一。
- **苏菲派与逊尼派**（问了穆斯林观众）：
  - 主流逊尼派来自一个更注重教义和当下世俗事务的主要分支。苏菲派（通常属**马立克**学派，原话说"Malachite"）教授一种更神秘的伊斯兰教，更关注来世，追求通过冥想、祈祷，有时根据地区还通过舞蹈和音乐，直接体验真主。
  - 一位沙特观众告诉他，最宽泛刻板地说，苏菲派在某些地方有时被看作"**嬉皮伊斯兰**"。"你们觉得这个描述准确吗？"
  - 不管怎样，马里南部大多数穆斯林信苏菲派，而北部是叛军控制、严格执行**沙里亚法**的社会，不认同南方同胞较温和的做法。
- **历史速通**：
  - 各部落和民族居住在上尼日尔河流域。
  - **马里帝国**成为主导力量；曼萨·穆萨前往麦加朝觐；马里帝国衰落。
  - 摩洛哥人击败桑海；廷巴克图成为首都；19世纪大饥荒。
  - 法国占领，成为**法属苏丹**；独立（1960年）；"这个人"成为总统（**莫迪博·凯塔**）。
  - 三月革命（1991年），政治体制改变。
  - 2012年北马里冲突；局势好转了一阵，但三年后又发生袭击。联合国维和部队持续提供援助。
  - 国家慢慢努力适应快速的人口增长。
  - （此后马里在2020年和2021年发生两次军事政变，2022年法军撤离，联合国维和部队于2023年撤出，军政府转而与俄罗斯合作。）
- **名人**：
  - 当然有**曼萨·穆萨**。
  - 音乐家：吉他手 **阿里·法尔卡·图雷**及其子 Vieux Farka Touré、"非洲金嗓子" **萨利夫·凯塔**、Ngoni Ba、Rokia Traoré、Oumou Sangaré。
  - 说唱歌手 Oxmo Puccino、作家 **阿马杜·汉帕特·巴**。
  - 摄影师 **马利克·西迪贝**、导演 Cheick Oumar Sissoko。

## 朋友圈（外交关系）
- "对马里来说，朋友很有意思：历史上他们已经和非洲很多人联系在一起，但现代政治和主流文化也起了很大作用。"
- **法国**：在非洲以外，大概是最亲近的朋友。作为前殖民地，法国关系密切，法国人是最大的游客群体，北部冲突后也是，冲突中法国军队也出手相助。（2022年两国关系破裂，法军撤离。）
- **俄罗斯和亚美尼亚**：冷战时期，马里某种程度上与俄罗斯结盟，但关系不算很强。如今俄罗斯和前苏联加盟共和国亚美尼亚仍有残留的联系，俄罗斯和马里互设使馆。（如今俄罗斯已成为马里军政府的主要安全伙伴。）
- **南北各有亲疏**："在非洲内部有点复杂，取决于你问谁。"
  - **南部**的人文化上与邻国更亲近，大概会说**布基纳法索、科特迪瓦、几内亚**是最好的朋友。
  - **北部**的人与**毛里塔尼亚、阿尔及利亚、尼日尔**更亲近，这些国家都有大量相同的民族，比如图阿雷格人和柏柏尔人。
- **阿尔及利亚**：话虽如此，和阿尔及利亚有点复杂。2012年发生了阿尔及利亚领事馆人质事件，此后阿尔及利亚总理计划与 MNLA 合作，所以马里南部和他们有些矛盾。

## 总结
"马里是一个拥有几千年历史的国家，讲述着一个由沙子、泥土、河流和黄金构成的故事。即使在冲突之中，他们也知道自己从哪里来，并让自己的故事延续下去。"下一集：马耳他。国旗见 [马里_国旗粉丝日](国旗粉丝日/马里_国旗粉丝日.md)。
