# 立陶宛（Lithuania）

> 开场重演拉脱维亚那集的梗：爱沙尼亚是忧郁的书呆子女孩，住在一对双胞胎姐妹隔壁。双胞胎："来和我们玩吧，爱沙尼亚！""欢迎来到更诡异的那个波罗的海姐妹，立陶宛。"主持人说："我知道有人说'别再叫这两个国家诡异了'，但我的回答是：这多少是真的，而且用得好的话并不是坏事，有人就喜欢诡异，好好利用就行。拉脱维亚建了监狱酒店，土库曼斯坦有'地狱之门'，还有国家靠鲸鱼呕吐物（龙涎香）赚大钱。"

## 政治地理
- **海岸线**："立陶宛也许是面积最大的波罗的海国家，但海岸线吃了亏。"
- **位置与行政区**：位于欧洲的波罗的海地区，北临波罗的海，与4国接壤。全国分**10个县**，首都**维尔纽斯**在南部。
- **库尔斯沙嘴**：
  - 记得那块被切开的飞地**加里宁格勒**属于俄罗斯吧？立陶宛和它共享一条著名的长条地带**库尔斯沙嘴**：一条约98公里长、有沙丘的沙质屏障，其中约54公里属于立陶宛（官方数据约52公里）。
  - 它几乎封住了整个**库尔斯潟湖**，只在**克莱佩达**港留了一个小开口。这里几乎是所有海运进入立陶宛的唯一通道，"拜托，没人会把货送到**帕兰加**那个小码头"。
  - 所以基本上，俄罗斯拥有潟湖的大部分，但立陶宛拥有唯一的出口。俄罗斯："嗯，我们不需要，我们在**维斯瓦潟湖**有出口，还有个好笑的星形要塞欢迎你。""俄罗斯，我等不及做你那集了。"
- **城市与机场**：维尔纽斯之后最大的城市是**考纳斯**和刚说的克莱佩达。这么小的国家居然有4个国际机场，按繁忙程度依次是维尔纽斯、考纳斯、帕兰加和**希奥利艾**。
- **欧洲地理中心之争**：
  - 立陶宛骄傲地宣称自己拥有**欧洲地理中心**，还在旁边建了纪念碑和雕塑公园。
  - 但其他国家纷纷反对："不对，错了，不。"连匈牙利都来争。
  - 还有一个声音说："吉尼斯世界纪录承认的是我的村子。"（指乌克兰等地也有类似说法。）"你自己判断吧。"
- **领土问题**：
  - 除了和北边拉脱维亚有点海上争议（关于石油储量）外，基本没有领土争议或怪事。
  - 还有那个伸进白俄罗斯的奇怪突出部，"我们在白俄罗斯那集讲过吧？"
  - 以及立陶宛从白俄罗斯那里"拿走"一块国家公园，"就算只给了我一条一米宽的走廊去到那里"。"哦对，我们讲过了。好，那我不用讲了，最省力。"
- **对岸共和国**：立陶宛有个微型国家**对岸共和国（Užupis）**，其实就是维尔纽斯一个波希米亚嬉皮风的街区，想显得很酷，像丹麦那集讲的**克里斯蒂安尼亚**。"自封但不被承认的自治，太酷了。"
- **黑暗历史**：
  - **大屠杀**：二战大屠杀在立陶宛规模巨大。这里曾是欧洲犹太人口最多的地方之一，有"**北方耶路撒冷**"之称。约25万犹太人几乎全被纳粹杀害（也有本地人参与），其中在**帕内列伊**发生了大屠杀，很多人被送到维尔纽斯的 HKP 562 强迫劳动营。如今各地有纪念馆、博物馆和展览纪念这些事件。
  - **废墟**：加入欧盟后移民率很高，很多城镇出现无人看管、日渐破败的房屋和建筑，比如**伊格纳利纳核电站**、维尔纽斯体育宫、工会大楼，还有**普拉托克利斯**核导弹发射基地，"对，核导弹基地"。
  - **猎奇景点**：还有**魔鬼博物馆**，以及在前苏联地堡里的"克格勃体验"：花钱扮演囚犯被吼、被审讯，还有警犬，"真迷人"。
- **景点**（"我不会念这些波罗的海词，太难了"）：
  - 多座城堡（如**特拉凯城堡**）、修道院。
  - 自由大道（考纳斯）、**三十字架山**。
  - 法西斯受害者纪念碑、缆索铁路。
  - 盲人博物馆、**猫博物馆**、错觉博物馆。
  - **弗兰克·扎帕**纪念碑。
  - 两个最具标志性的文化地标，最能让你感受立陶宛：
    - **十字架山**：有超过10万个十字架，没人确切知道它是怎么开始的。梵蒂冈说那是充满力量的圣地，当地人却觉得有点瘆人。
    - **女巫山**：一个雕塑公园，满是面目阴森的木雕，描绘的是古代异教时期立陶宛民间传说里的角色。
- "立陶宛有点像一个怪异的'异教加天主教'、爱森林、技术进步却保存完好、天色阴沉的国家。"

## 自然地理
- "第三次解释基本一样的东西了。你们大概会想跳过这段，为了留住你们，这是 Keith 弹贝斯。"
- **国名**：主持人说立陶宛（Lietuva）这个名字来自 lietus，意为"**雨**"，象征雨水充沛、土地肥沃。国旗集里他承认这其实是个玩笑，不是真的，词源仍有争议。
- **地形**：全国分四大部分：平坦的海岸、略高的高地、中部低地和**波罗的海高地**。最高点**奥克什托亚斯山**只有约293米（官方约294米），所以立陶宛是**最平**的波罗的海国家。
- **湿地与森林**：和其他波罗的海国家一样，到处是沼泽、湿地和森林，占国土1/3以上。
- **河湖**：
  - 最长的河是**涅曼河**，发源于白俄罗斯，流经考纳斯，在**考纳斯水库**蓄积。
  - 最大的湖是部分与白俄罗斯共享的**德鲁克夏伊湖**。"等等，白俄罗斯那集我讲过吗？还有一个岛被白俄罗斯和立陶宛分开，两个岛和两个半岛在另一个湖上……天哪，我白俄罗斯那集做得真好，让我现在省事多了。"
- **白鹳**：
  - 国鸟是**白鹳**。立陶宛的白鹳筑巢密度世界最高。
  - 他们相信白鹳在你家附近筑巢是好运，甚至有专门的节日：**3月25日**。
- **琥珀**：立陶宛以**琥珀**闻名。波罗的海沿岸拥有世界上已知最大的天然琥珀矿藏，琥珀加工基本从立陶宛的一个小镇开始（"我不会再试着念了"）。
- **农业与饮食**：大部分土地可耕，1/3以上已开垦。国菜有：
  - **冷甜菜汤**（粉红色的 šaltibarščiai）。
  - 卷心菜卷。
  - 一种乳制品，凝乳类。
  - "蚁丘蛋糕"、**树蛋糕（šakotis）**、罂粟籽卷。
  - 血汤、立陶宛奶酪。
  - 最具标志性的是**齐柏林饺**（cepelinai，大土豆饺子）。

## 人口
- **开场**："立陶宛人嘛，好得像棉花糖。"主持人想起在东京遇到的立陶宛观众 Giedra："我本想找你帮这集提供信息，但找不到你的邮箱。如果你在看，告诉我准不准。"
- **基本情况**：
  - 约280万人，是波罗的海地区最大的经济体，GDP 也最高。
  - 约88%是立陶宛族，约6%波兰人，5%俄罗斯人，其余主要是斯拉夫人，比如乌克兰人、白俄罗斯人，以及其他少数族群。
  - 用**欧元**（2015年加入），C 型插座，靠右行驶。
- **与拉脱维亚的分道**："如果你真想感受一切波罗的海的东西，立陶宛就像是震中。"
  - 波罗的海地区是欧洲最后皈依基督教的地方。至今和拉脱维亚、爱沙尼亚一样，古老的异教传统和民间传说仍通过节日、艺术品和习俗延续。
  - 简言之，立陶宛受天主教影响更深，拉脱维亚受新教影响更深。立陶宛和波兰组成联邦，一度成为欧洲最大的国家，而拉脱维亚被德国人和普鲁士人等占领。
- **语言**：
  - 拉脱维亚语和立陶宛语是世界上仅存的两种波罗的语，它们的"老大哥"**古普鲁士语**在19世纪消亡（一般认为在18世纪初）。
  - 这两种语言非常古老，"比希腊语还老"（原话如此，属于夸张）。一半的词和名字以 s 结尾，很多以 -unas、-as 结尾。
  - 立陶宛语被认为可能是仍在使用的**最古老的印欧语言**，有人说它还保留着与印度古代**梵语**相关的词，比如"火"：梵语 agnis，立陶宛语 ugnis；"神"：梵语 devas，立陶宛语 dievas，等等。"仔细看，巧合之近很奇怪。"
  - "在立陶宛语里说谢谢，你只要打个喷嚏就行。"因为"谢谢"是 **ačiū**，听起来像"阿嚏"。
- **金发蓝眼与性别比**：
  - 波罗的海地区有两样东西比例最高：**金发蓝眼的人**，以及**女性对男性的比例**。立陶宛在男女比例上通常排第二或第三，介于拉脱维亚和爱沙尼亚之间，大约每位女性对应0.88名男性。
  - 部分原因是：战争时期大量男性被杀，以及吸烟、酗酒、自杀等导致的死亡。
- **自杀率**：
  - "在 Geography Now，我们不回避争议，但尽量客观报道。"不幸的是，立陶宛的人均自杀率常在世界前三，很多次排第一。
  - 奇怪的是，这个黑暗事实给立陶宛和立陶宛人蒙上了一种奇怪的浪漫化形象，以至于人们只是耸耸肩、坦然承认。
  - 有个立陶宛人设计了一个"**安乐死过山车**"概念，设计目的是杀死乘客。立陶宛还被选作虚构人物**汉尼拔·莱克特**的童年故乡。"加上一些异教雕像，和成千上万装饰过度的十字架摆在一片沼泽地里，砰，你就有了完美的恐怖片布景。"
  - "不过说真的，立陶宛不全是 jump scare，更像一个传说之地：古老的习俗依然存在，人民英勇，是第一个脱离苏联帝国的国家（1990年3月11日宣布）。而且他们爱篮球。"
- **历史速通**：
  - 异教部落；"这个人"统一了所有部落成为国王，"真的是他们整个历史上唯一的国王"（**明道加斯**，国旗集里更正了名字）。
  - 与条顿骑士团的战争。
  - 1400年代与波兰组成**波兰-立陶宛联邦**，成为欧洲最大的国家。
  - 短暂殖民过非洲和加勒比的部分地区（原话如此，实际是拉脱维亚的库尔兰公国），殖民地后来被卖掉、失去。
  - 被俄罗斯、普鲁士和奥地利瓜分。
  - **偷运书籍时代**：沙俄禁止拉丁字母印刷，人们偷运书籍保住语言。
  - 1918年短暂独立，但俄罗斯人又来了；纳粹也来插一手；又回到苏联。
  - 欧洲历史上最血腥的游击战，3万多名立陶宛男子牺牲（"**森林兄弟**"）。
  - 与其他波罗的海国家一起进行"歌唱革命"，90年代终于独立。
  - 加入欧盟和欧元区。
  - 不知怎么成了欧洲的**篮球之都**，"篮球对他们来说几乎是宗教"。
- **名人**：
  - 很多篮球运动员，比如**萨博尼斯**等。
  - 最有名的大概是"那个本该成为国王却在加冕前去世的人"（维陶塔斯大公）。
  - 画家**丘尔廖尼斯**、导演**约纳斯·梅卡斯**、作家等。
  - 有部分立陶宛血统的名人："Jason Sudeikis、查尔斯·布朗森、John C. Reilly、西恩·潘、萨莎·拜伦·科恩、鲍勃·迪伦、威廉·夏特纳、Pink、Anthony Kiedis。"
- **冷知识**：
  - 他们没有复活节兔子，而是有**复活节奶奶**。
  - 人均**热气球**数量世界最多。
  - 有自己的"国家香水"。
  - 网速世界最快之一。
  - 在屋里吹口哨被认为不吉利，"否则房子会爆炸烧掉"。

## 朋友圈（外交关系）
- 立陶宛是最大的波罗的海国家，却常是最少被宣传的那个，不过还是有些国家进了它的核心圈子。
- **欧盟**：作为欧盟成员，大部分贸易和生意要通过邻国，尤其是德国和瑞典。
- **冰岛**：第一个承认其独立的国家，两国关系很好，维尔纽斯甚至有一条以冰岛命名的街。
- **美国、巴西、英国**：各有立陶宛之外最大的侨民社群，多年来加强了关系。"我刚发现我家乡洛杉矶有个小立陶宛区。"
- **格鲁吉亚和乌克兰**：立陶宛爱它们，因为同样有前苏联的历史。在任何对抗俄罗斯的政治运动中都支持它们，甚至提供外援。
- **波兰**：像前男友，一开始在一起很开心，后来吵架分手，但随着时间过去释怀了，现在只是朋友。
- **爱沙尼亚**：像童年好友，相处得很好，但毕业后各奔东西，爱沙尼亚越来越迷恋芬兰。
- **最好的朋友：拉脱维亚**：最终最好的朋友毫不意外是小双胞胎妹妹拉脱维亚。"虽然岁月让两人长得有点不一样，她们依然一起前行，延续传统，共享古老神秘的波罗的海魅力。"
