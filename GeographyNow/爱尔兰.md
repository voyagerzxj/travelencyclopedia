# 爱尔兰（Ireland）

> Geography Now 视频 #203 · 发布于 2017-08-30 · [观看视频](https://www.youtube.com/watch?v=yWZiO7YNoPQ)
> 开场：爱尔兰是主持人八分之一血统的来源。这集请来爱尔兰实习生 **Peadar**（帮节目做过很多动画，"为国流的血"系列的第一段动画就是他做的），专门从爱尔兰飞来。Peadar 纠正："念'帕德'（Padder）！"主持人："太晚了，我叫你 Potter 叫了两年，不改了。"Peadar："我来纠正他说错的地方，大家别担心。"然后给了主持人一拳："原来是这种感觉。"

## 政治地理
- **外号**："翡翠岛"、"欧洲的挡雨盾"、"麦乐鸡块"。"还有个镇叫 Dingle（叮当）。"
- **位置**：欧洲第三大岛，位于北大西洋，与大不列颠隔着北海峡、爱尔兰海和圣乔治海峡。"注意到我刻意避开了'不列颠群岛'这个词吗？""对，做得好。"
- **两部分**：
  - 一般说的主权国家指**爱尔兰共和国**，占全岛六分之五，这集主要讲它。
  - 北部剩下的部分属于英国，"自己都不太清楚该叫什么"：有人叫省，有人叫地区，有人叫构成国，"总之英国抓着它"。Peadar："你能想象，这让爱尔兰人过去有过一些'有意思'的感受。"
  - 奇怪的是，北爱尔兰的人可以选择国籍：英国、爱尔兰或者两者都要。
- **边界怪事**：
  - 西边，北爱边界伸进农田，在一个叫 Manger 的小村结束，给爱尔兰共和国留下一条约7公里宽的走廊，从 **Bundoran** 进入多尼戈尔郡。
  - 芬河对岸有一块半飞地，入口只有0.1公里宽，仍属莫纳亨郡。这反过来给了英国一块小外飞地：一片无名土地，只有三户农家。
  - 除了游过河，唯一的进出办法是走岛上"改名次数最多的国际公路"：爱尔兰的 **N54**，进入北爱变成 **A3**，进入那块外飞地又变回 N54，大约两公里后又变回 A3，再回到共和国时又是 N54。"爱尔兰、英国、爱尔兰、英国、爱尔兰！"Peadar："这就是我的恋爱史。"
  - 英国还说："与其沿福伊尔河一直到福伊尔湖，不如向左拐穿过农田，把整座**德里**城拿走，逻辑！"
  - 对爱尔兰人来说，整个岛（包括北爱）就是"爱尔兰"。
- **行政区**：
  - 爱尔兰共和国分26个郡，很多人会加上北爱的6个，说32个。
  - 还有利默里克和沃特福德两个市郡联合议会，以及都柏林、戈尔韦、科克三个市议会，所以共和国共31个地方当局；算上北爱的郡和首都都柏林，技术上是37个。主持人："对吧？""对！"
- **四大省**：历史上爱尔兰分为四个省，至今很多人仍这么称呼：**康诺特、伦斯特、芒斯特、阿尔斯特**。北爱常被称为"阿尔斯特"，因为包括了这个历史省份的大部分郡。
- **城市与机场**：都柏林之后最大的城市是**科克**和**利默里克**，最大的机场是都柏林、科克和**香农**机场。如果算北爱尔兰，**贝尔法斯特**在两份名单上都会排第二。
- **岛屿**：除了本岛，还有数百个小岛。人口最多的是科克附近的 Great Island、梅奥的**阿基尔岛**，以及戈尔韦的 Gorumna 和**阿伦群岛**。
- **景点**：
  - **圣三一学院**、**健力士展览馆**。
  - 比吉萨金字塔还古老的新石器时代墓葬**纽格莱奇墓**。
  - **卡舍尔岩**、威克洛的**格兰达洛**、科克的**巧言石**。
  - 《星球大战》结尾的拍摄地**斯凯利格·迈克尔岛**。
  - 有自己"国王"的**托里岛**。
  - **斯科蒂娅墓**：据说埋着一位埃及公主（"我都不知道这个。""你都不知道？我在 Atlas Obscura 上找到的"）。
  - 人质丘、塞德田野（Céide Fields）、天空花园。
  - **胡克角灯塔**：欧洲仍在使用的最古老的灯塔，Peadar 就住在旁边。
  - **Sean's Bar**：现存最古老的酒吧，可能是全世界最古老的。
  - 教堂、修道院、城堡、石桌坟、古墓多到列不完。
- **别去圣殿酒吧区**：都柏林的 **Temple Bar** 是游客陷阱，"遇不到真正的爱尔兰人，别去"。Peadar："去 Coppers 吧。"
- **喝酒**：主持人："你们很会喝一品脱吧？"Peadar："爱尔兰人会，但我其实不喝……自从我杀了那个人。""哦……等等，什么？"

## 自然地理
- "爱尔兰很绿。完！"Peadar："还有一点别的。"
- **地形**：
  - 爱尔兰是一座冰川雕刻过的矿物和砂岩岛，有约12条小山脉，大多在北部、西部和南部。
  - 地图上看，东海岸比较平直，西海岸却参差不齐，满是海湾和半岛，"就像把一团黏土往一个方向抹开"。主持人："嘿嘿，One Direction（一个方向）……"
- **山、河、湖**：
  - 最高峰**卡朗图厄尔山**，约1000米。
  - 最长、最重要的河是**香农河**。
  - 全岛最大的湖是北爱的**内伊湖**；只算共和国的话，是西戈尔韦的**科里布湖**。
- **海岸奇观**：
  - 西部有最著名的自然地标**莫赫悬崖**，从海里笔直升起约120米。
  - 往北还有 **Slieve League 悬崖**。
  - 北爱有**巨人之路**：一系列六边形的火山岩柱台阶伸入大海。（主持人爱听 Peadar 念"hexagonal"。）
- **气候：英国的挡雨盾**：
  - 爱尔兰纬度虽高，却像英国的"挡雨盾"，承接了北大西洋暖流从加勒比一路带来的暖空气。
  - 所以虽然和加拿大纽芬兰纬度差不多，爱尔兰要暖约9°C，很少到冰点，几乎不下雪。
  - 代价是雨特别多："一年一大半都在下雨，只有大概两个月晴天，然后又是倾盆大雨。不会让你们抑郁吗？"Peadar："你觉得呢？喝酒在爱尔兰可是件大事。"
- **农业与啤酒**：
  - 雨水充沛让植物和农业繁盛，有了标志性的绿色。常见作物有**土豆**（spuds）、甜菜，以及大麦、燕麦、小麦等谷物，其中很大一部分拿去做最有名的产品：**啤酒**！
  - 主持人："爱尔兰没有啤酒，就像墨西哥没有塔可、韩国没有泡菜、阿根廷人没有探戈（原话误说成'莎莎'）、Bob Saget 没有心灵感应激光眼。"
  - Peadar：啤酒文化深入爱尔兰人的骨髓，连神父和修女都会和客人喝一杯。主持人："顺便说，《圣经》从不谴责喝酒，只谴责醉酒，要知道自己的限度。"Peadar："对，我们经常去告解。"
- **美食**：土豆煎饼 **boxty**、土豆面包、**苏打面包**、培根配卷心菜，汤多到列不完，比如香肠土豆炖菜 **coddle** 和**爱尔兰炖肉**，还有黑布丁、生蚝配健力士。几乎什么都配各种做法的土豆。
- **动物**：约26种哺乳动物，比如赤狐、欧洲刺猬、白鼬、侏鼩鼱、獾，以及唯一的本土陆地爬行动物**胎生蜥蜴**。
- **圣帕特里克赶蛇**：Peadar 说这个传说大概不是真的。爱尔兰因为与欧洲隔绝，很可能从来就没有蛇。"而且圣帕特里克大概不是爱尔兰人，他是威尔士人。"

## 人口
- **"craic"**：主持人问 Potter（又挨了一拳）："当爱尔兰人意味着什么？"Peadar："我们爱 craic（快活、乐子），一周七天日夜都要 craic！"然后缉毒局警察冲进来："不许动！"Peadar："常见误会！我们说的不是毒品（crack）……"警察："拒捕！"
- **基本情况**：
  - 约480万人，算上北爱600多万，出生率欧盟最高。
  - 约83%认同爱尔兰族，约9.5%是其他国籍的白人，其余是亚裔、黑人，"谁知道呢，大概还有些魔法巫师"。
  - 欧元，G 型插座，靠左行驶。
- **超越刻板印象**：多亏现代媒体，人人都多少见过刻板印象中的爱尔兰文化，比如大河之舞、矮妖精，"或者跳大河之舞的矮妖精"。但爱尔兰身份认同有一整个深厚的世界。
- **爱尔兰语**：
  - 技术上爱尔兰（共和国）是英语和爱尔兰语的双语国家，但英语用得多得多。爱尔兰语和苏格兰、威尔士，以及某种程度上法国布列塔尼的凯尔特语言有亲缘关系。
  - 主持人："你以为冰岛那集之后安全了？爱尔兰语来了：mh 读 v，dh 读 g 或 y，bh 和 fh 有时读'呜'。"
  - Peadar 让他念几个词：Ar aghaidh leat（"继续"）、tábhachtach（"重要"）、leithreas（"厕所"），都没念对。第四个"其实是我编的"。
  - 很长时间里，讲英语的统治者压制和不鼓励爱尔兰语，好几代人长大后几乎不会自己的母语。
  - 如今爱尔兰语大幅复兴，是大多数中小学的核心科目。虽然不到一半的人自称流利，只有少数社区在日常生活中真正使用，但这门语言活到了21世纪。
  - 所有公共标识都是双语的，还有爱尔兰语电视台、电台，甚至网络报纸。
- **历史速通**：
  - 石器时代、凯尔特文化传入、酋邦、至尊王、基督教。
  - 维京人、诺曼人、建城堡、黑死病。
  - 亨利八世脱离天主教会并进攻；阿尔斯特殖民与准英国统治；**克伦威尔**；战争。
  - **沃尔夫·托恩**领导失败的起义。
  - **马铃薯大饥荒**，大量人移民美国和苏格兰。
  - 盖尔复兴，北方不同意，对天主教徒的冲突和迫害。
  - 地方自治、地方自治被搁置、一战、**复活节起义**（原话误说成 Eastern Rising）。
  - 爱尔兰共和军作战、爱尔兰内战（自由邦派获胜）、二战中基本保持中立。
  - 1969年民权游行，北爱冲突加剧。
  - 加入欧盟、《耶稣受难日协议》、"凯尔特之虎"、金融危机，但仍在发展前进。
- **凯尔特人**：
  - 爱尔兰人来自一个叫**凯尔特人**的悠久族系。（发音是"Keltic"，不是"Seltic"，"那是波士顿凯尔特人队"。）
  - 几千年前凯尔特人遍布欧洲大陆，但帝国崛起和各族混战把他们一路往西推到了海岛上。
  - 凯尔特人有一套复杂的部落或氏族体系，各家族统治特定地区，有自己的首领和国王。这也是为什么那么多爱尔兰人姓氏带 **Mac/Mc** 或几乎是爱尔兰独有的 **O'** 前缀，意为"……之子"或"后代"。
  - 基督教之前，凯尔特人主要是农民和牧牛人，有异教和**德鲁伊**根源，罗马人还记录过一些有争议的做法。
  - 后来基督教和天主教传入，至今仍很重要。
- **萨温节**：
  - 某些古老传统保留了下来，比如 **Samhain** 节。Peadar 纠正发音："读'Sow-in'。""可你说 mh 读 v！""看情况，有时读有时不读。""啊，你们的语言！"
  - 萨温节后来成了**万圣节**，流行到全世界。但最早用的是**芜菁灯**，不是南瓜。
- **神话**：
  - 大家都听过矮妖精，但还有芬恩·麦克库尔和**芬尼亚传说**，"库丘林"（猎犬）。
  - 迪尔穆德和格兰妮的故事，类似亚瑟王传说中的特里斯坦与伊索尔德。
  - "还有很多很多。"
- **运动**：两项最流行的运动几乎别处都不玩：**盖尔式足球**和**爱尔兰曲棍球（hurling）**。主持人："就像爱尔兰版魁地奇？"（又挨一拳）"别叫它魁地奇。"Peadar 给他看了一根曲棍（hurl）。
- **口音**：爱尔兰没有统一的口音，不同地区有不同方言。Peadar 示范了科克口音、都柏林口音，还学了连姆·尼森。主持人："幸好你来了，我要是自己学，视频上传几小时内就会被捅死。"
- **名人**：
  - 化学家**罗伯特·波义耳**。
  - "爱尔兰的 PewDiePie"（字幕没录到名字，应是 Jacksepticeye）。
  - 摇滚乐手菲尔·莱诺特（主持人说他在圭亚那那集把名字念错成 Philly Nott，道歉）。
  - "One Direction 的那位"（应是尼尔·霍兰）。
  - 北爱的**连姆·尼森**；法斯宾德一半爱尔兰血统，"大概算吧"。
  - 格斗选手**康纳·麦格雷戈**。
  - 还有"上次国旗星期五马来西亚观众说的"：**Westlife** 和 **Boyzone**。
- "想了解更多音乐、舞蹈、文学、象征、文物、传统、节日、服装、习俗和传说，就去看爱尔兰剧《Fair City》或《泰德神父》。"Peadar："或者跟爱尔兰人聊聊。""不，电视更好，电视从不出错。"

## 朋友圈（外交关系）
- "不管在世界哪里，遇到爱尔兰人都算你走运。"
- **法国和西班牙**：作为欧盟成员，爱尔兰与欧洲大陆邻国关系紧密，尤其是天主教国家法国和西班牙。
  - 法国人和爱尔兰人历史上常联手对抗英国，约60%的中学生学法语。
  - 西班牙不仅亲近、生意好，还是爱尔兰人的头号旅游目的地，约四分之一的人口每年至少去一次。
- **立陶宛人**：出人意料的是，90年代苏联解体后立陶宛人大量涌入爱尔兰，成为仅次于英国人和波兰人的第三大移民群体。"波兰人到处都去，不奇怪，还记得他们占冰岛人口约8%吗？"
- **英国**：尽管有过去的恩怨，爱尔兰和英国相处得不错。很多进口来自英国，爱尔兰人在英国很多，几乎是英国日常氛围不可或缺的一部分。
- **最好的朋友：苏格兰和美国**：
  - **苏格兰**：凯尔特兄弟，从一开始就共享文化，也经历过同样的斗争和苦难。马铃薯饥荒后大量爱尔兰人去了**格拉斯哥**（原话误说成利物浦），受到"表亲"的欢迎。主持人还提到《勇敢的心》里爱尔兰雇佣兵倒戈、加入苏格兰表亲那一幕，"别管那可怕的口音"。
  - **美国**：像他们最喜欢的、更大更壮的小表弟。爱尔兰约30%的出口去美国。马铃薯饥荒后几十万爱尔兰人涌入埃利斯岛，如今约3500万美国人自称有部分或全部爱尔兰血统，集中在东海岸新英格兰，约是爱尔兰人口的7倍。主持人："连我都有！谢谢我从没见过的祖父！"

## 总结
- Peadar 来总结："爱尔兰一路'康纳·麦格雷戈'式地熬过了战争、饥荒、经济衰退、糟糕的矮妖精形象，还有杰拉德·巴特勒在《P.S. 我爱你》里那可怕的爱尔兰口音（'你是苏格兰人，这不该那么难！'）。尽管有点情绪问题，我们还是街区里最酷的孩子。爱尔兰，你这个美丽的、醉醺醺的一团糟的国家！"
