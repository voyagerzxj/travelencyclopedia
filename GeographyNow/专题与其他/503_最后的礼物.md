# 最后的礼物（The Last gift.）

> Geography Now 视频 #503 · 发布于 2023-12-25 · [观看视频](https://www.youtube.com/watch?v=eP45XoKpNGI) · 个人故事 · 韩国之行
> 主持人讲述自己与**韩国**之间复杂的关系，以及16年后为外婆**生日**回到韩国。另见 [韩国](../韩国.md)、[160_父亲去世](160_父亲去世.md)。

## 和韩国"复杂"的关系
- **血统**："我的订阅者都知道，我提过很多次：我是**半个韩国人**。我父母也都是**半个**韩国人，说来复杂。我从小就很清楚自己一半的韩国血统：我甚至有小时候穿**韩服**的照片，还办过**百日宴**。它从小就**融入**了我的身份，因为那是我的**历史**、我的**传承**。"
- **青春期的"韩国热"**：
  - "我大概十几岁的时候，做了所有高中生都会做的事：拼命**尴尬**地把某样东西变成自己的**身份**，对我来说就是'当韩国人'这件事。我**痴迷**于当韩国人：我让爸妈多教我说**韩语**（我读写更好），学**歌**、学**传统**。"
  - "在所有朋友圈里我通常都是那个'**标配亚洲人**'，我其实很**喜欢**，喜欢有一样东西让我**与众不同**。"
  - "有一次特别糟：高中**午饭**时，我带了一份**韩文报纸**，坐下来读，等朋友来。我虽然读不懂全部，还是在读。朋友们来了：'嘿你在读什么？''哦，就是份报纸，我想跟上**韩国**新闻。''哇，你真能读？''对，它说……''那什么意思？''哦，是**政治**的事，你不会懂的，你知道，那些**朝鲜**人。'回头看真的很**尴尬**，但那就是我，我痴迷到最后真的去**住**在了韩国。"

## 18岁的韩国经历
- **信仰**："一点背景：我在一个**韩国教会**里长大。我在频道上很少谈**信仰**，更别说我自己的信仰，因为这个频道是讲**地理**的，不是讲我的。但频道是我创的，所以某个时候我总得有点**个人**参与。"
- **去韩国教书**：
  - "高中一毕业，我去参加了一个教会**退修会**。退修会结束后，我得到一个在一所**教会高中**教**英语**的机会。"
  - "我父母反对，不想让我留下，想让我回来上**大学**。但18岁的我说：'爸妈，我是**成年人**了，我知道我在做什么，这是个好机会。'"
- **被剥削与逃离**：
  - "结果那个项目真的很**糟**。长话短说，他们基本是在**利用**、**剥削**我，因为我会说英语，此外还发生了很多其他坏事。"
  - "我不打算讲所有疯狂的**细节**，因为我不喜欢人们为了**播放量**或**同情**而**消费**悲惨故事或**创伤**故事。我不这么玩，那不是我的**性格**，我不是来讲悲惨故事的。"
  - "那个项目糟到我其实得**逃**出来：他们有**监控摄像头**，监视人们确保没人**逃跑**，太扭曲了。**校长**有过多**教条**式的权威，太疯狂了。多年后我得知他被**撤职**了，我很高兴，但那仍是一段很扭曲的时光。"
  - "我逃到我**舅舅**家，他给我买了回美国的**机票**，我永远**欠**他的。那是我最后一次去韩国。"
- **关于信仰**：
  - "你大概以为这是一个我如何**离开**信仰的故事。不，不是。虽然现在我对自己的**灵性**会有点**坦白**：我仍认同自己是**基督徒**。我处在一个奇怪的位置，还在弄清楚自己是**谁**，承认自己是个**破碎**的人。我很久没去**教堂**了，但我终究无法**否认**它、无法**放下**它。"
  - "直到今天，我的 Instagram 上还写着'**蒙基督救赎的罪人**'。我不想放俗气的**经文**或基督教**语录**，我只想让人知道：我是那个**破碎**的**罪人**，**耶稣**才是那个好人，就这样。不知为何我没法把它从 Instagram 上**删**掉。"
  - "离开那个项目教会我：人**永远**成不了**神**。那是另一个话题。"
- **16年的抗拒**："从那一刻起，韩国对我来说有点**死**了。我再也不想回去，不想再当韩国人，不想说韩语、读写韩语，不想在美国和其他韩国人来往，不想吃**韩国**菜，不想和它有任何关系。我**受够**了，我**讨厌**当韩国人。这种情绪跟了我大约16年。"

## 回到"祖国"
- **外婆的电话**："去年我外婆给我和我妈打电话：'我**生日**快到了，我想让你们来。'外婆年纪大了，你知道，我们知道**时候**快到了。"
- **决定**："我脑子里想起上次在韩国的一切。但后来我意识到：那时我还**年轻**，是一个想**控制**一切的扭曲项目的一部分。我现在是**成年人**了，有自己的**钱**，可以按自己的时间做事，而且过去16年韩国变了很多。我是要为16年前发生的事一直**怨恨**，还是回去、回到**祖国**？是的，我可以**放下**，没关系，我们去韩国。"
- **出发**："我在 **LAX**，咖啡，去韩国。出发前我得做个**仪式**……好，我准备好了。""我们到了，看这个，太酷了，**祖国**。"见了**舅舅**和**舅妈**。
- **和表亲们**："外婆生日还有几天，所以在那之前是和**表亲**们玩的时间。"去唱 **K歌（노래방）**、喝**酒**的传统、拍**大头贴**（"我表亲坚持要拍这个大头贴"）。
- **济州元素**：看到 **石头爷爷（돌하르방）**："你能看到这些石头，熔岩石，**济州**风格的建筑，'Harubang'。"
- **盘索里**："我想来这里的主要原因是会在这个小**亭子**里发生的一件事：一位女士会来表演我最喜欢的音乐风格之一：**盘索里（판소리）**。我想**看**这个。"
- **独自探索**："今天会很特别，因为在我去过韩国的所有次数里，我**第一次**要以自己的方式**独自**探索这个国家。"
  - **乐天世界大厦**："我想看这个想了好久，上次我来韩国时还没有：**乐天世界大厦**，韩国**最高**的建筑，看起来好酷。"
  - **见订阅者**："我还见了住在这里的一些订阅者，有些人路上**认**出了我，我请他们吃**晚饭**。这位 **Vincent** 请**我**吃了晚饭，别以为我忘了你，伙计，谢谢你来。"
  - 最后和**妈妈**一起去了**景福宫**（原话说"Kung"），还有一顿和**家人**的**惊喜**晚餐："说实话我一直想做这个。"
- **中秋**："回去后，是时候和外婆一起过 **秋夕**（韩国的**感恩节**）了。"

## 重访"那个地方"
- "明天是外婆的生日，但我还有最后一件事要做：我得去看看**那个地方**。"
- **熟悉的路**："太疯狂了，16年后我还**清楚**地知道怎么去：坐哪趟**火车**、在哪站下、从车站怎么**走**过去。我不知道我为什么这么做，也许我只是需要某种**了结**，但我就是知道我得**最后**去看一次。"
- **故地**：
  - "这是16年前我和韩国有过很糟糕经历的地方。他们还有那栋**金枪鱼**楼（原话如此），我记得我在那里过了一夜，因为我有点**叛逆**，想'我要**通宵**打游戏'，就在那里睡了，有点像**青年旅舍**。"
  - "**乐天利**还在，那里以前有**泡菜汉堡**，现在停售了。那是他们以前让我们**每个**周三早上**四点**踢**足球**的**体育场**。"
  - "就是这里，我找到了：这就是16年前基本**毁了**我人生的地方，就是那栋楼。它还在。我不敢**进去**，因为那里有**监控摄像头**，以前没有。所有这些树以前都是很小的**树苗**，现在长大了。"
- **逃跑路线**："后面以前有个**停车场**，那边有道**围栏**，我就是从那里**逃**出去的：有块**松动**的木板，然后我绕到后面一直到这个**废品场**，有一扇方形的小**活板门**，我记得它。我看看还在不在……我记得那面有方门的墙大概在这，我想16年后他们把它**堵**上了，但大概在那。我**爬**过去，翻过围栏，我**自由**了。"
- **释然**："再次看到这个地方有点**怪**，那么多**回忆**涌上来。我承认有些甚至是**好**的。虽然大多数是坏的，但我得承认这是我人生中真正**磨炼**了我的一个篇章。我**静静**地走开，**再也没**回头。……好吧，其实我在他们的**围栏**上**撒了泡尿**才走。"

## 外婆的生日
- **小孩桌**："我是个**成年**男人了，但作为在场**最年轻**的人之一，我还是得坐**小孩桌**。不过没关系，**尊敬长辈**，而且食物很好。"
- **重新觉醒**："整个经历还是很疯狂，我想这是我**需要**的。我踏足的每一处都像是**新**的、**美**的，像是这整个经历在**唤醒**我内心的某样东西：突然我想**多说**韩语，想**多当**韩国人。但它好像一直就在我**里面**。归根结底，我很高兴能体验我另一半的**传承**。"
- **两份礼物**：
  - "我妈是**艺术家**，她想送外婆一份礼物：一幅根据外婆**十几岁**时的照片画的**画像**。"
  - "然后问题来了：我要送她什么？我能做的不多，除了一件事。虽然我把韩国身份**搁置**了16年，我还记得一样东西：我爸**去世**前教过我一首**盘索里**歌。盘索里是韩国最**传统**、最**著名**的音乐之一，一种**激烈**的**叙事**歌唱。我还记得这首歌，叫《**鸟打令（새타령）**》，意思是'**鸟之歌**'。我想我大概得给外婆**唱**，而她从没听过我唱歌。"（他为外婆唱了这首歌。）

## 后记
- **外婆去世**："几个月后外婆去世了。幸好我妈留下了，能陪在她**最后**的时刻。说实话，我不仅很高兴能见到她，还得**感谢**她：如果不是她，我大概永远不会**回去**，我内心的**韩国**身份大概会一直被**压抑**、很少出来。"
- **感谢妈妈**：
  - "我也得感谢我妈。我爸去世后，我有点得承担起**供养**我妈的角色。一开始我承认我不知道会怎样，因为我从没和我妈**单独**住过：'呃，我想当**单身汉**，有自己的生活、自己的地方。'"
  - "结果她是**最棒**的：她懂我的**幽默**，我所有朋友都爱她，都叫她'**妈**'，甚至不叫她名字。她比任何人都**懂**我，她是我的**第一**。所以我人生做的几乎一切，都只是为了确保她**开心**、**舒适**。"
- **Geography Now 是工具**："Geography Now 不是我人生的**目的**。我把 Geography Now 更多看作一个**工具**，一个我能用来给她**幸福**生活的工具。Geography Now 最好的事之一，是它让我能带她**周游世界**、和她一起经历这些疯狂的**冒险**。她从没见过那么多东西，而我能当那个**带她看**的人。她看到那些东西、她开心时，我也**开心**。所以我真的很高兴这一切发生了。"
- "就这样，我没别的要说了，我只是想和你们**分享**这些。"
