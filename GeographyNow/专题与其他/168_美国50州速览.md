# 美国50个州速览（All 50 U.S. states summarized）

> Geography Now 视频 #168 · 发布于 2017-05-18 · [观看视频](https://www.youtube.com/watch?v=hWpzs9QcCCY) · 专题

**缘起**：Geography Now 的观众大多来自美国，但美国以外的观众也很多，有人好奇每个州是什么样。主持人用一两句话"概括"每个州，大多是半开玩笑的刻板印象，下面照录要点，玩笑归玩笑。

| 州 | 主持人的概括 |
|---|---|
| 阿拉巴马 | "白人黑人都穷，但派对一样疯"，"Roll Tide!"（大学橄榄球口号）。南方邦联是从这里开始的。 |
| 阿拉斯加 | "美国的冰箱"，储备资源、等真出事再开采。最大最冷的州，有北极熊和尤皮克原住民。 |
| 亚利桑那 | 大峡谷之州，美国的"沙漠之王"，有最大的印第安保留地纳瓦霍族保留地。 |
| 阿肯色 | "读读《红色羊齿草的故事》就懂了"。养狗率全美最高。 |
| 加利福尼亚 | 主持人的家乡州。如果独立，经济规模能排世界第七，但仍很依赖联邦。世界娱乐之都；硅谷有三家全球最大的科技公司；多元，什么都有。 |
| 科罗拉多 | 最健康的州，肥胖率最低，因为大家爱去户外爬山。"有人请你吃巧克力松露或布朗尼时小心点"，大麻已合法。 |
| 康涅狄格 | "受够了纽约的人搬去的更温和、更干净的郊区"。 |
| 特拉华 | 第一个成为州的州，"基本也就这点可说了"。 |
| 佛罗里达 | "美国的沼泽游乐场"。房子几乎没有地下室，往下挖一点就是水。因为太多美国人去不了加州的迪士尼乐园，就建了更大的迪士尼世界，接着冒出了一大堆主题公园。 |
| 佐治亚 | 桃子州。可口可乐总部，全美最繁忙的机场（亚特兰大），还有儿童选美比赛。 |
| 夏威夷 | 最后一个成为州的州。之前是一个波利尼西亚国家，有自己的君主，末代女王是**利留卡拉尼**。其余你都知道：草裙舞、冲浪、菠萝、夏威夷宴会。 |
| 爱达荷 | 大多数美国人只知道它土豆产量最高。也有温泉、峡谷等秘境。"我总觉得爱达荷人藏着很多我们不知道的黑暗秘密。" |
| 伊利诺伊 | "林肯之地"，虽然林肯生在肯塔基。主持人童年大部分时间在这里长大。很多人只知道芝加哥，却不知道它在哪个州。历史上被称为美国的"屠宰场"：得州的牛运来这里屠宰，也因为有黑帮历史。 |
| 印第安纳 | "伊利诺伊烦人的弟弟"，从芝加哥手里抢走了加里镇，于是能说自己是迈克尔·杰克逊的出生地。还有印第安纳波利斯500赛车，作家约翰·格林也来自这里。 |
| 艾奥瓦 | "平坦无聊到只能想办法自娱自乐的州"，摔跤很强。 |
| 堪萨斯 | 中西部的心脏，《绿野仙踪》里桃乐丝的家，全美最平的州。 |
| 肯塔基 | 棒球棒、波本威士忌、肯德基、赛马（肯塔基德比），还有存放国家黄金的**诺克斯堡**。 |
| 路易斯安那 | 美国少数还有集中讲法语（某种程度上）社区的州。以河湾沼泽闻名，饮食里有大量小龙虾、螃蟹、爬行动物等"沼泽生物"，"和美国其他地方都不一样"。 |
| 缅因 | 龙虾州，强悍的大西洋水手住在雾蒙蒙悬崖上、有灯塔的房子里。 |
| 马里兰 | 最富裕、受教育程度最高的黑人社区所在地。游泳奥运冠军菲尔普斯的家乡。超爱螃蟹：蟹饼、烤蟹、煮蟹。 |
| 马萨诸塞 | "美国的图书馆"，有哈佛（主持人说它"无可争议是世界最好的大学"）。马萨诸塞人分三种：高傲的、粗犷的、粗犷的知识分子，都觉得自己比另外两种强。 |
| 密歇根 | "对不起，你在20世纪初干得那么好"，曾是最富的州之一，后来出了美国史上最大的市政破产案（底特律）。 |
| 明尼苏达 | 主持人的出生地。"美国的芬兰"，确实有很多芬兰人和其他北欧人。"万湖之州"。他说这里的人是全美最好看的之一，只是口音有点好笑，他自己就是那种口音长大的。 |
| 密西西比 | 美国最地道的"深南方"州。最胖的州，爱教堂和山核桃。奥普拉、猫王等很多名人生在这里。 |
| 密苏里 | 中西部的门户，像肯塔基的异卵双胞胎，内战时也是缓冲区。以堪萨斯城烧烤闻名，堪萨斯城大部分其实在密苏里。"老年人的拉斯维加斯"（布兰森），还有收集俗气小摆件放进瓷器柜的人。 |
| 蒙大拿 | "又大又空、多山，干脆整个当印第安保留地算了"：有黑脚族、扁头族、克劳族、夏延族等。 |
| 内布拉斯加 | 玉米和牛排，"基本就这俩景点"。美国第二富的巴菲特住在这里。 |
| 内华达 | "加州喝醉的女朋友"。拉斯维加斯撑起了这个州的约80%，"我们还把核废料埋在那里"。 |
| 新罕布什尔 | 小小的秋日仙境，红叶美丽，有木制廊桥。常春藤盟校里最小的**达特茅斯学院**在这里。 |
| 新泽西 | "很有钱，也很愤怒"，不想摆脱刻板印象，干脆接受：要么在舞池里疯，要么对彼此疯。 |
| 新墨西哥 | "活在亚利桑那阴影下的弟弟"，后来《绝命毒师》爆红，练出了六块腹肌。**罗斯威尔**据说是外星人着陆的地方。 |
| 纽约 | 美国历史的很多根源在这里。19世纪移民的后裔大多能追溯到**埃利斯岛**。有全美人口最多的城市纽约。人们骄傲、气场大、永不睡觉。 |
| 北卡罗来纳 | 莱特兄弟1903年在这里完成首次动力飞行。可口可乐的死对头**百事可乐**诞生于此。 |
| 北达科他 | 因**立岩保留地**和达科他输油管道争议出了名。原住民很多，也有很多挪威裔，有些在家仍说挪威语。 |
| 俄亥俄 | 最普通、最典型的美国体验：玉米热狗、夏夜萤火虫、烟花和嘉年华。阿米什人口全美最多。到了大选就是一场血战（摇摆州）。 |
| 俄克拉何马 | 美国龙卷风之州，中西部都有龙卷风，但俄克拉何马受灾最重。 |
| 俄勒冈 | 起初是边疆伐木州，满是拿斧头和电锯的壮汉。后来嬉皮士住不起旧金山，就都北上了。现在是"伐木工、素食者和文艺青年的奇怪混合体，甜甜圈很好吃"。 |
| 宾夕法尼亚 | 美国的"历史之州"，国会曾在费城开会，"首都本该在这儿"。想重温美国历史就来这里。 |
| 罗得岛 | 最小的州，"既不是岛也不是半岛，搞什么？"它是最初13州之一，也是动画《恶搞之家》里虚构城市 Quahog 的所在地。 |
| 南卡罗来纳 | 爱烟草、软糖、核桃。有最大的**嘎勒人（Gullah）**社区，他们说受非洲影响的克里奥尔语，有自己的节庆。 |
| 南达科他 | "另一个达科他"。有美国最标志性的总统山**拉什莫尔山**，还在建世界最大的雕像**疯马纪念碑**。也有很多原住民，主要属苏族。 |
| 田纳西 | "得克萨斯暗恋的邻家女孩"。阿巴拉契亚山区的中心，山民、蓝草音乐，乡村歌手都来这里争取唱片合约。 |
| 得克萨斯 | 曾经是独立国家，"得州什么都更大"。美式足球基本是宗教，烧烤和烧烤酱各算一类食物，到处是牧场。和流行看法相反，大多数得州人并不排斥墨西哥人和墨西哥文化，还发展出了融合两者的 **Tex-Mex** 文化。 |
| 犹他 | 美国的"摩门教之州"，盐湖城是摩门教总部，超过一半的人口登记为教会成员。滑雪很棒，有圣丹斯电影节，还有主持人在全美最爱的地方**纪念碑谷**。 |
| 佛蒙特 | 像新罕布什尔的小双胞胎，产的枫糖浆更多。除此之外就是 Ben & Jerry's 冰淇淋，"要是这家公司破产，他们就成下一个密歇根了"。 |
| 弗吉尼亚 | 美国一切开始的地方：英国人来建了个小镇（詹姆斯敦），然后有了宝嘉康蒂的故事，"迪士尼拍得'非常准确'"。和宾夕法尼亚并称两个"历史之州"。 |
| 华盛顿州 | 常青之州。"跟俄勒冈一样的剧本，只是把嬉皮士换成电脑宅"：微软、亚马逊、Expedia、星巴克、波音都诞生于此。80年代有一座火山爆发（圣海伦斯火山）。 |
| 西弗吉尼亚 | 内战时站在北方联邦一边的最南的州："不，弗吉尼亚，我要离开你。"主持人说它是最"老"的州，平均年龄约40岁（实际年龄中位数最高的是缅因州）。煤炭很多来自这里。 |
| 威斯康星 | 美国的奶乡。主持人认为每个人都该至少有一个威斯康星朋友，他就有一个，是给 Geography Now 写主题曲的人。威斯康星人最好相处，故事最多。 |
| 怀俄明 | 最著名的国家公园**黄石**在这里：瀑布、间歇泉、温泉，很多野牛，"像真牛仔的训练场"。 |
| **附送：华盛顿特区** | 人口比两个州还多，却不是州，而是联邦特区。总统"有时"住在这里，国会"大部分时候"在这里开会。所有博物馆和史密森学会免费，但热狗贵得离谱。到处是雕像、纪念碑和监控摄像头，"玩得开心，但别太开心"。 |

- 还有波多黎各、关岛、北马里亚纳、美属维尔京群岛等领地，"以后再讲"。
