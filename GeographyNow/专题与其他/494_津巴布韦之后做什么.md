# 津巴布韦那集之后 Geography Now 要做什么？（What will Geography Now do AFTER the Zimbabwe episode?）

> Geography Now 视频 #494 · 发布于 2023-09-12 · [观看视频](https://www.youtube.com/watch?v=U4JeIgMhclQ) · 频道近况 · 主持人独白
> "这是我被问得**最多**的问题，我来**回答**一下。"
> 当初定下的计划见 [037_会介绍哪些国家](037_会介绍哪些国家.md)。

## 回顾
- **起点**：
  - "Geography Now 的**国家集**快结束了，关键词是**国家集**。我的老订阅者知道，几年前我做过一个视频，说我会按**字母**顺序做联合国193个正式**主权**成员国。"
  - "从那以后真是一段**狂野**的旅程。我当初在一间**客厅**里开拍，那时我**睡**在客厅里，和**室友**一起租住一位**亚美尼亚**老太太家的**后屋**。"
- **成就**："此后 Geography Now 成了 YouTube 上**第一个**、也是**最大**的为世界每个国家做完整**信息**档案的频道。它给我和节目上的朋友带来了那么多很酷的**机会**，这是我人生近**十年**的一段疯狂旅程。"

## 为什么开始做 Geography Now
- **多元的童年**："原因很多，很多其实源于**个人**原因。我在**芝加哥**一个非常**多元**的街区长大，学校里很多孩子来自不同**背景**，很多是**双语**的。我会听到孩子们说**波兰语**、**乌尔都语**、**希腊语**或**俄语**；我是半个**韩国人**，身边一直有**韩语**。"
- **好奇心**："我看着这些孩子想：'你为什么和我**不一样**？你说的是什么**语言**？你从**哪**来？'后来长大一点我才明白，他们来自一个来自**远方**的家庭，这让我意识到世界上有很多地方、很多不同的人。我开始好奇：这些人为什么和我不同？你们的族人来自什么地方？我想这就点燃了我对身边的人和世界的**社会动态**的兴趣，那大概是九岁左右。"
- **视觉型学习者**：
  - "我是**重度**视觉型学习者，没法靠**听**来学东西，读**说明书**也很差，必须看**图**或**演示**才能学会。"
  - "冷知识：四年级时我被分进了**慢读班**。我还以为自己很**特别**，因为可以在白天中途离开教室，去学校外面那个神秘的**活动板房**。我走进去，发现周围的孩子都有点'**慢**'，我想：哦，我想我是他们中的一员。我阅读很差，还有**言语障碍**，被送去上**言语矫正**课。我是个**问题**小孩，真的。"
  - "但后来我意识到我不**笨**，我只是**无聊**，学的东西我都不感兴趣。英语课让我们读那些**蠢**书，我对它们没兴趣。顺便说我从没读过任何**必读书**，我全靠**胡扯**考试，拿 C- 过关。"
- **地图集**："但有一样东西我能看好几个**小时**：**地图集**。因为我听到孩子们说'我来自**波兰**'，我想：波兰是什么，在哪？哦，波兰在地图上。'我家来自**巴基斯坦**'，巴基斯坦是什么？我会看地图：那就是你家来的地方，可我在**芝加哥**，而他们在那么远的地方。我意识到这个世界很**大**，我住的这个小**泡泡**之外有那么多事，我对此非常好奇。"
- **职业迷茫**："但小时候有这种爱好，并没有一条直接的**职业**路径：'我喜欢了解世界，我能做什么？当**外交官**？但我不想只关注一个国家，我想了解**整个**世界，有什么工作能谈论整个世界？'"

## 想当旅行节目主持人
- **Globe Trekker**：
  - "后来我搬到了**洛杉矶**。我不是**演员**，不是**音乐人**，但我想当**旅行节目主持人**。我记得我想上 PBS 的节目《**Globe Trekker**》（**布莱德利·库珀**也上过那个节目）：主持人们周游世界，讲他们去的国家和地区，见当地人，吃当地食物，太**酷**了。我想当《Globe Trekker》的主持人之一，我**迷**死那个节目了。我会去**图书馆**借 **DVD**（那时还有 DVD），把能找到的每一集都看了。"
  - "有一天我鼓起**勇气**给自己录了像，给《Globe Trekker》寄了**试镜**视频，但我**从没**收到回音。我都不知道他们看没看，也许看了不喜欢，也许投稿太多没看到，我不知道。"
- **到处碰壁**："没收到回音后我想：好吧，也许不是《Globe Trekker》，但也许我可以去别的**电视网**申请当旅行节目主持人。我上了**主持**课，寄**样片**，努力**试镜**，一直想把自己'**卖**'给这些电视网。所有这些试镜太**累**了，最后就是**没人要**我，这对我的**自尊**打击很大。"

## YouTube 上的空白
- **契机**："那时 YouTube 开始真正**起飞**。我只知道我爱了解世界，爱认识世界各地的人，爱旅行，想在人生中以某种方式做这一切。如果你想学东西，YouTube 通常是个好去处，所以我去了 YouTube，却发现 YouTube 上**没有**做地理的频道。"
- "有些频道是'**巴西**的10个趣事'，或者某人旅行：'哦看我，我在**巴哈马**的海滩上玩得很开心。'那就是当时的地理'资源'，没人做地理**教育**频道。所以我想：好吧，那我来做。"
- **要做就做好**："但我脑子里很清楚我想怎么做这个节目。我不想做成那种在卧室里用**摄像头**拍的俗气 **240p** 节目，我想做一个全长、**半**像样的节目，有**动画**，因为我爱动画，爱**动态图形**，那是我学习的方式，我是视觉型学习者。"
- **自学动画**："所以我花了大约三个月跟我朋友 **Jason** 学做动态图形，他教我，我自己做了前六七集的动画。动态图形真的很**难**，我无法想象人们怎么会**喜欢**做那东西。后来我认识了更多帮忙的人，开始让更多**订阅者**上节目，节目开始成长，太疯狂了。"
- **名字的由来**："冷知识：我最初想把 Geography Now 叫 **The Geography Show**，但有人已经用了。我还是想在名字里有 geography，也许短一点、好记一点：'geography 嘿，geography 嗨，geography **now**……对，就是它。'"
- **片头片尾曲**：
  - "冷知识：片头曲 'It's time to learn geography **NOW**' 是我写的，最后那声 'NOW' 真的是**我**在喊。"
  - "但片尾曲是 **Bill** 做的，他大概五分钟就编出来了。他是个**天才**，就开始**吹口哨**、**拍手**、弹**尤克里里**，就这样。Bill 需要更多**认可**，他是个很酷的人，每一集我还把他列为主题曲作者。"
- **"金手铐"**："节目开始起飞，做得很好，我有那么多想做的**点子**，但在做完最后一集**津巴布韦**之前，我没法追求任何**长期**计划，有点像'**金手铐**'。我刚开始做 Geography Now 时以为大概四年就做完了，'哦就是七八分钟的**小**视频'。但节目越来越**长**、越来越**复杂**，订阅者又要更多**环节**：'为什么不讲**体育**？为什么不讲**音乐**？为什么不讲**美食**？'所以集数越来越长，因为你们想要越来越多，我给了你们，现在人们又**抱怨**太长。我在网上永远**赢不了**，所以随便吧，我现在就做我想做的。"
- **第一件T恤**："顺便说，这是第一件 Geography Now T恤，已经**停产**了。如果你们谁真有这件，你是真正的 **OG**，我们很久以前就不卖了。"

## 津巴布韦之后
- **出去看世界**：
  - "我人生大约十年都在**演播室**里谈论世界，我想是时候出去**看**它了：出去见你们，去发现世界**真正**是什么样。我不想**谈论**它，我想**看**它，我是视觉型学习者。我知道偶尔我能在节目里旅行，做 **Geography Go** 这样的项目，但在我看来**不够**。记住，我想当的是**旅行**节目主持人，不是**演播室**里的主持人。"
- **最喜欢的视频**："很多人问我：'Barbs，你做过的视频里最喜欢哪个？'我总告诉他们是那次**寻根**之旅：我爸**去世**后，我和我妈去了我们'所谓'**祖籍**的那些国家。虽然它播放量不高，但它会**永远**是我最喜欢的视频。这种东西是我**绝对**爱在频道上做的：去某个地方**探索**，展示给你们。"
- **自己的 Globe Trekker**："在某种程度上，我想做我**自己**的《Globe Trekker》。我上不了《Globe Trekker》，那我还不如做我自己的。我人生有种奇怪的**模式**：没人要我，所以我就做我自己的，而且做得比那些不要我的人**更好**。"
- **乌克兰的启发**："今年早些时候我去了**乌克兰**（见 [475_战时的乌克兰之旅](../实地探访/475_战时的乌克兰之旅.md)），做了那个小小的**纪录片**视频，那其实是我在频道上做过最好玩的事之一，视频反响也很好。我真的想做更多那样的东西。"
- **有故事的纪录**："我想出去**记录**一切，但要有**故事**、有**梗概**、有**计划**、有明确的**目标**。我不想做旅行 **Vlog**：'嘿我在这，看这座城堡，我玩得很开心'之类的，不。我需要一个**理由**、一个**目的**、一个**故事**，去覆盖人们还没怎么见过或听过的**新领域**。我不想给你们看你们在**维基百科**上就能查到的东西，我想给你们看你们从没听过、从没见过、查不到、从没**发现**过的东西，连我自己都没发现过的东西。这就是津巴布韦之后我想带 Geography Now 走的大方向。"
- **频道不会死**："频道不会**死**，我会让它**继续**。这不是 Geography Now 的**结束**，只是我想做得有点**不一样**。"
- **四个观察员地区**："另一个我常被问的问题：你会做联合国四个未被完全承认的**观察员**地区吗？**科索沃**、**台湾**、**巴勒斯坦**和**梵蒂冈城**。我确实想做一些与这四个地方相关的内容，但不在**演播室**里，我宁愿**亲眼**去看。如果我为这四个地方做任何东西，必须是**亲自**去，不是在演播室里讲。我还没有计划，但如果你们来自那些地区……找**梵蒂冈**的人会很难，我是说也许那里的某个**神父**或**修女**看 Geography Now，也许。"
- **新系列**："除了旅行纪录片，我还有一些别的想做的事，我想你们会喜欢，但这是个**秘密**：我有一个很酷的新**系列**点子，你们得等着，会很酷。"
- **寻找外祖父**："另一个项目有点**私人**，但我一直没时间做，因为一直忙 Geography Now：我想找到我**母亲**那边的**亲生**外祖父。其实应该不难，我们有一些关于他的**信息**，只是一直没去做。我和我妈谈过，她说她觉得自己现在**准备好**了，终于准备好找出她的亲生父亲是谁。如果他已经去世，也许我们能见见他的**家人**，我不知道，这是我们想做的一件事。"
- **其他**：
  - "我一直想写一本**书**，但因为 Geography Now 从没时间。"
  - "最后，我试镜过《**极速前进**》（The Amazing Race），但后来不寄试镜视频了，因为太忙。我觉得在做完津巴布韦之前上那个节目不合适，我想先把所有国家集**做完**再去试镜。我可能上不了、可能不被录取，但我还会继续试镜，因为我**爱**那个节目，即使我永远上不了，我也会一直看、一直爱它。"

## 结语
- **重塑自己**："长话短说，频道会继续，只是会有点**不同**。也许你们会喜欢，也许会讨厌，但我就做我想做的、玩得开心，你们随时欢迎**一起**来。那句话怎么说来着：要么**重塑自己**，要么**退休**。我还没准备好退休，所以我得重塑自己、搞清楚方向。谁知道，我可能**惨败**、失去一切，但至少我曾在历史上某个时候当过 YouTube 上的'**地理人**'。现在有一堆别的地理频道，比我做得还好，但随便，我玩得很开心。"
- **感谢订阅者**："非常感谢你们这么多年一直关注 Geography Now、和我们一起开心地了解世界。也非常感谢所有帮我了解你们国家的人，说真的，频道一半以上的**信息**来自我的订阅者，那是我**最大**的资源。我了解一个国家时，不是先去维基百科，我先**私信**我的订阅者，他们回我，我们来回聊，然后我去**见**他们、和他们聊，或者让他们上节目，那是了解一个国家**最好**的方式。节目好，是因为你们帮忙**做**了它。"
- "我想说我**爱**你们，但我不**认识**你们，大部分我都不认识，我只认识亲自见过的一小部分。而且**爱**是个很怪、很**重**的词，我是半个**亚洲**人，我们不太说这个词，有点**肉麻**。'我爱你'，用**行动**表示你爱某人就好，别**说**。那就是我和我的**韩国**文化。"
- "Stay cool，stay tuned。……好**激烈**。"
