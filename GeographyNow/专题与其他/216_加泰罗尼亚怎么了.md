# 加泰罗尼亚怎么了？（What is up with Catalonia?）

> Geography Now 视频 #216 · 发布于 2017-10-28 · [观看视频](https://www.youtube.com/watch?v=_zn0kNjLwSs) · 专题

**背景**：主持人和母亲刚从寻根之旅回来。这又是一个"填充周"。很多观众来信问：Geography Now 会做加泰罗尼亚吗？截至2017年10月27日星期五，加泰罗尼亚议会投票宣布独立，"那我们是不是得做一期加泰罗尼亚？"他的明确回答是："我还不知道。"宣布独立不是成为国家的唯一标准，还有很多步骤和程序要走。

## 加泰罗尼亚是什么，怎么走到今天
- **历史**：
  - 很久以前，加泰罗尼亚与今天西班牙的其他部分（阿拉贡地区）是分开的。1150年，阿拉贡女王**佩德罗尼拉**嫁给巴塞罗那伯爵，合并了他们儿子将继承的领地。
  - 1707年加泰罗尼亚又试图分离，随后在瓦伦西亚打了一仗，七年后又在加泰罗尼亚打了一仗。等剩下的岛屿也被拿下，现代西班牙的版图就完成了。
- **叛逆者**：加泰罗尼亚一直是各地区中的"叛逆者"（某种程度上巴斯克也是，"那是另一个故事"）。他们有自己的语言、饮食、传统、节日、习俗，"你能想到的都有"。
- **自治**：现代西班牙建立以来，历届西班牙政府在这里管理和执行西班牙法律都有点困难，最后干脆举手投降："好吧！"30年代和70年代给了它自治权。
- **经济**：
  - 加泰罗尼亚长期是西班牙的工业和海上中心，临地中海，在金融、旅游和高科技服务方面都很强。
  - 它是西班牙最富裕的地区之一，约占全国 GDP 的五分之一，主持人说约3150亿（原话说成"3.15亿"），和马德里相当。它的经济体量超过整个葡萄牙或香港。
  - 人均 GDP 约3.5万，比韩国、意大利、以色列还富。
  - 所以可以想象2000年代末金融危机后他们（尤其是富人）的反应：长期以来，他们觉得自己繁荣的经济产出像是西班牙其他地区的"拐杖"。

## 2017年的事件
- 加泰罗尼亚自治区主席（**普伊格德蒙特**）呼吁举行公投，地区议会批准。西班牙首相**拉霍伊**不高兴，称其违宪。
- "本来到此为止就好了，但事情变得更糟"：西班牙政府动用武力阻止人们去投票站，没收传单海报，有些地方甚至升级为暴力冲突。
- 宣布独立后，西班牙参议院援引了1978年宪法中**从未用过的第155条**，授予中央政府全权接管加泰罗尼亚。

## 加泰罗尼亚算国家了吗
- 不容易说，因为光想独立、宣布独立还不够，还牵涉很多事。
- **对比南苏丹**：最近一个从别国分离出来的国家是**南苏丹**。最大的区别是，南苏丹能证明自己长期被边缘化，让国际社会和苏丹都相信除了分离没有更好的选择。双方都投了票，连苏丹也投票同意它分离。"所以尽管整件事一开始就一团糟，但其实有很多合作。"加泰罗尼亚的情况不是这样，西班牙非常不想放弃加泰罗尼亚。
- **欧洲人的看法**：主持人在寻根之旅中和很多欧洲人聊过，大家看法不一。很多欧洲公民的顾虑是不想看到欧盟开始瓦解，他们希望欧盟团结，这种事对欧盟不好看。但也有人完全支持加泰罗尼亚独立运动。
- **如果真独立了**：
  - 一切都得从零开始重建：大量文书、外交拓展、建使馆、派外交官，等等。
  - 还得想办法偿还欠西班牙中央政府的**520亿美元**，"可能有点尴尬"。
  - 按法律，从现有欧盟成员国分离出去的国家会立即失去欧盟身份，必须重新申请，可能要花很长时间（他猜他们大概会想重新加入），又是一大笔钱和时间。
  - 还得获得承认。按国际法的"**构成说**"，要成为国家，在某种程度上需要被其他国家承认。
- **他的结论**：
  - "说到底我不知道会发生什么，现在还太早。"
  - Geography Now 按字母顺序讲联合国承认的完全主权国家。如果加泰罗尼亚能做到这一点，成为联合国正式成员、得到足够多国家承认、建立外交关系，节目就会讲加泰罗尼亚。否则就得等讲完津巴布韦后，在讲争议地区、自治地区和构成国的部分再讲。
  - （后来的情况：西班牙随即解散了加泰罗尼亚政府并实施直接管辖，普伊格德蒙特出走比利时。独立宣言没有得到任何国家承认，西班牙宪法法院宣布其无效。）
