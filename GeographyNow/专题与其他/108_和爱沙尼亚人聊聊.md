# 和爱沙尼亚人聊聊：Artur Rehi（LET'S TALK TO AN ESTONIAN! Ft. Artur Rehi）

> Geography Now 视频 #108 · 发布于 2016-09-29 · [观看视频](https://www.youtube.com/watch?v=OVpDKoj6Okw) · 访谈

**缘起**：《调研爱沙尼亚》那期被版权投诉，视频还在但不能盈利。主持人想"补救"一下，正好上期出现的爱沙尼亚 YouTuber **Artur Rehi** 就住在他家不到一英里外的洛杉矶，于是请他来聊。

- **怎么看拉脱维亚人和立陶宛人**：
  - 常开的玩笑是"**拉脱维亚人有六个脚趾**"。
  - 拉脱维亚的酒更便宜。芬兰人来爱沙尼亚买酒，爱沙尼亚人去拉脱维亚买酒，拉脱维亚人"大概去俄罗斯买"。
  - 爱沙尼亚人觉得比拉脱维亚人强，拉脱维亚人也觉得比他们强，"其实谁也不比谁好"。
- **波罗的海还是北欧**："当然是北欧。看我们的国旗，蓝得像天堂一样。"
- **能听懂多少芬兰语**：两种语言很多词听起来一模一样，意思却不同，"你以为听懂了，人家说的是别的"。两国之间常闹笑话，但爱沙尼亚人尊敬、爱戴芬兰，"他们是我们的大哥"。
- **最有名的爱沙尼亚人**：
  - 作曲家 **阿尔沃·帕特**。
  - 科学家 **卡尔·恩斯特·冯·贝尔**，曾印在爱沙尼亚纸币上，"后来欧元来了，抢走了我们的钱"。
  - 铁饼冠军 **格尔德·坎特**。
- **荡秋千运动**：Artur 说他两米高，玩不了，"矮一点大概更容易"。主持人演示了一下，自己只到他肩膀。
- **代表食物**：
  - 国菜 **kama**：一种混合谷物粉，基本就是酸奶拌谷物粉。
  - 酸菜、**血肠（verivorst）**。
  - 黄油面包配 **kilu**（腌小鱼），"很好吃，不像冰岛的臭鲨鱼"。
- **为什么科技这么强**：苏联解体、"歌唱革命"后，爱沙尼亚人想摆脱一切红色的东西，连国旗上都没有红色。苏联代表陈旧，西方的科技代表新鲜和酷，于是全国朝那个方向奔去。
- **爱沙尼亚人怎么娱乐**："通常是一个人待在房间里不跟任何人说话，在棺材里睡觉。"其实也有社交：唱歌、跳舞、喝酒。不过有人喝酒喝到死，"这很悲哀"。
  - **歌舞节**：大型的每5年一次，小型的每年都有。
  - **女多男少**：爱沙尼亚女性对男性的比例全世界最高，Artur 的解释是"因为男人把自己喝死了"。
- **在美国的文化冲击**：
  - 人很开放、礼貌、爱笑（"当然洛杉矶以表面著称"）。
  - 办事要排长队，在爱沙尼亚"啪一下就办好了"。
  - 美国"一切皆有可能"，但要靠自己拼，潜力大，风险也大。
- **为什么爱沙尼亚很棒**：
  - "我们有便宜的伏特加。"
  - 爱沙尼亚是最后几个还保留古老习俗的民族之一，民族的悲伤和历史还流在血里。
  - "我们很小，不打扰别人，就像亚马孙雨林里的一个部落，小小的，但我们在那里。"
  - 他们靠孤独和痛苦滋养文化：所有歌、所有民族故事都关于血、悲伤和暴力。
  - 主持人总结出一句格言："**It hurts so good**（痛得真爽）"，建议写在国旗上："三条横带，三个词。"
