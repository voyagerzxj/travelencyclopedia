# 你应该知道的世界最大最重要的政府间组织（The world's largest + most important IGOs you should know）

> "这周做一个**参考视频**，你们可以反复用它来分享和查资料。"内容截至2019年，括号里补了此后的主要变化。主持人说"政府间组织（IGO）"，但混进了 WWF 这类**非政府组织**，下面照录。

## 全球性组织
- **IMF（国际货币基金组织）**：总部华盛顿，1944年成立，促进世界贸易，有184个成员国（原话如此，现为191个），基本是帮助改善成员国的财务状况，"所以你能理解为什么很多人想加入"。
- **WWF（世界自然基金会）**：总部瑞士沃州**格朗**，1961年成立，是世界最大的保护组织（实为非政府组织），主要目标是保护濒危动物及其栖息地。
- **WHO（世界卫生组织）**：总部**日内瓦**，联合国的专门机构，促进全球卫生事务，帮助提高各国医疗标准，监测各地疾病。
- **UNICEF（联合国儿童基金会）**：总部纽约，1946年（原话说1947年）成立，帮助改善海外儿童及其母亲的健康和福利，尤其在发展中国家。
- **UNESCO（联合国教科文组织）**：总部**巴黎**，1945/1946年成立，促进各国的文化、科学和教育，"所以他们每年列出那些**世界遗产**"。（美国2025年再次宣布退出。）
- **世界银行**：总部华盛顿，1944年成立，旨在减少世界贫困，向发展中国家提供贷款。
- **WTO（世界贸易组织）**：总部日内瓦，协助国家间的贸易协议，有153个成员（原话如此，现为166个），约占世界贸易的97%，"像全世界商业交易的中间人"。
- **G8 / G20**：
  - 在每年轮换的东道国举行会议的峰会。**八国集团**基本由世界主要工业国组成，各国首脑在峰会上讨论安全、贫困等全球问题，"至少本应如此"。
  - 2014年**俄罗斯**因吞并**克里米亚**被暂停成员资格，2017年宣布退出，名称又回到 **G7**，"直到欧盟有点补了俄罗斯的位置，挺怪的"。
  - G8占全球 GDP 一半以上、购买力平价40%以上。
  - **G20** 是 G8 加接下来的12个国家（加欧盟），合计约占世界人口2/3、世界贸易80%，每年还邀请一个特邀国列席。（2023年**非洲联盟**成为 G20 正式成员。）
- **NATO（北约）**：
  - 总部布鲁塞尔，是欧洲和北美（基本就是美国和加拿大）多国之间的**军事同盟**。
  - 二战后作为对苏联和东方集团的回应成立，最初12国，"现在大概29个吧"（2019年为29个；北马其顿2020年加入；**芬兰**2023年、**瑞典**2024年加入后为32个）。
- **UN（联合国）**：
  - 可以说是最大的组织，有193个成员国和2个观察员国（**梵蒂冈**和**巴勒斯坦**）。
  - 联合国大会就维和、人权等作出决定。世界各地有很多联合国**维和**任务，比如**塞浦路斯**的联合国缓冲区，以及很多其他地方，大多在非洲和中东。
  - "基本上如果世界有问题，联合国就讨论，尽力而为，更像是全世界的人在一起说话。"
  - **UNHCR（联合国难民署）**：保护世界各地的难民和被迫流离失所者，也协助自愿遣返，即帮想回原籍国的人回去。
- **OECD（经合组织）**：总部巴黎，自称"致力于民主和市场经济，提供一个比较政策经验的平台"。"基本上是那些很富裕的国家聚在一起，讨论能为世界做什么。"（现有38个成员。）
- **INTERPOL（国际刑警组织）**：
  - 总部法国**里昂**，为全球执法部门提供调查支持、专业知识和培训。尤其关注三类跨国犯罪：**恐怖主义**、**有组织犯罪**和**网络犯罪**，但基本涵盖所有其他类型的犯罪。
  - 他们还用数据库信息等把各国的执法网络连接起来，"有点像**世界警察**"。
- **ICC（国际刑事法院）**：
  - 总部荷兰**海牙**，有权起诉国际罪行，特别是**种族灭绝罪**、**危害人类罪**、**战争罪**和**侵略罪**。
  - "这是非常严肃的法院，除非真的出大事、非常疯狂才会用到，联合国安理会会把案件移交给它，是件大事。"
  - （注意别和联合国的**国际法院（ICJ）**混淆，后者审理国家间争端。）
- **OPEC（石油输出国组织）**：
  - 总部**维也纳**（"尽管大多数产油国在中东"），有14个成员国（原话如此，现为12个），约占世界石油产量的44%，拥有世界已探明石油储量约81.5%，这给了他们对全球油价的重大影响力。
  - （2016年起与俄罗斯等组成 **OPEC+**；卡塔尔2019年、安哥拉2024年退出。）

## 各大洲的区域组织
- **美洲国家组织（OAS）**：总部华盛顿，由美洲35个成员国组成，覆盖西半球约10亿人。**古巴**的参与权曾被暂停，但从未被正式开除，2009年紧张缓和后恢复了（古巴本身并未重新参与）。"基本是让美洲各国保持对话的组织。"
- **欧洲委员会（Council of Europe）**：
  - 总部法国**斯特拉斯堡**。"基本上如果你不在欧盟，最接近的就是它。"管理欧洲各国以及**阿塞拜疆**、**亚美尼亚**等跨大洲国家，合计约8.5亿人。
  - 其宗旨是在欧洲维护人权、民主和法治，但不能制定有约束力的法律（实际上**欧洲人权法院**的判决对成员国有约束力），"又是'我们来聊聊我们希望推行的事'"。
  - "顺便说，你会看到很多这类组织。"（2022年**俄罗斯**被开除。）
- **非洲联盟（AU）**：
  - 有两个主要政治中心：**亚的斯亚贝巴**和**约翰内斯堡**（原话如此，泛非议会设在约翰内斯堡附近的米德兰），2001/2002年成立。
  - 基本包括非洲大陆所有国家，外加一个给**撒拉威阿拉伯民主共和国（西撒哈拉）**的特殊席位，"这就是为什么**摩洛哥**长期退出了联盟，但2017年又回来了"。
  - 联盟各国合计约10亿人（现约14亿），在联盟所有官方语言中，唯一的本土语言是**斯瓦希里语**。
  - （2020年代因政变，马里、几内亚、布基纳法索、尼日尔、苏丹、加蓬等国曾被暂停成员资格。）
- **亚洲合作对话（ACD）**："这是最接近覆盖整个亚洲大陆的合作组织"，2002年成立，管理非常松散，像 G8 一样每年在不同地点举行峰会，秘书处在（科威特，原话说"亚洲理事会总部在东京"）。
- **太平洋岛国论坛（PIF）**：
  - 秘书处在斐济**苏瓦**，"这很怪，因为斐济曾被暂停五年"（2009–2014年政变后）。
  - 好笑的是**澳大利亚**是成员，但它一国的人口就是其他所有成员的两倍（原话如此），经济规模是其他所有成员合计的五倍，"所以澳大利亚在这个组合里有点重要"。
  - 2011年美国领地获得观察员地位，2016年**法属波利尼西亚**和**新喀里多尼亚**获得正式成员资格。
- **北美**：
  - **NAFTA / USMCA**：
    - **北美自由贸易协定**刚刚重新谈判，正在过渡为 **USMCA（美墨加协定）**。长话短说，这基本是美国、加拿大和墨西哥之间的**自由贸易区**。NAFTA 在三国首都都有秘书处办公室，按 GDP 是最大的贸易集团之一。
    - 2017年起的谈判决定把它改成"美墨加协定"，"基本是一回事，只在汽车和铝生产等出口、免税物品限额等方面有一些小改动"（2020年7月生效）。
- **中美洲议会（PARLACEN）**：总部危地马拉城，"基本是除**哥斯达黎加**外所有中美洲国家聚在一起，讨论如何在地区层面推进。他们干成了多少事，由你判断"。
- **加勒比共同体（CARICOM）**：
  - 秘书处在**圭亚那**的**乔治敦**，有15个正式成员，大多讲英语；5个准成员，全是英国领地；8个观察员国。
  - 目标基本是在经济、金融和社会上整合所有加勒比国家。
  - 他们分为两派：一半较不发达，一半较发达，所以按政策较发达的国家要帮助较不发达的国家。
- **安第斯共同体**：
  - 基本就是哥伦比亚、厄瓜多尔、秘鲁和玻利维亚。智利和委内瑞拉曾是成员，但后来退出了。
  - 这是一个**贸易集团**和**关税同盟**。成员国甚至有自己的**安第斯共同体护照**（红金色），成员国之间往来相对容易，入境不需签证，还便利经济和商业交易。
- **南方共同市场（Mercosur）**：
  - "基本是其他所有国家"：委内瑞拉被暂停，玻利维亚是候选国（2024年成为正式成员），其他国家都只是观察员（联系国）。
  - 和安第斯共同体一样，它是关税同盟和自由贸易区，人员、商品和货币流动顺畅，还在成员国间促进税收和投资激励等。
- **欧盟（EU）**：
  - "当然大家都听说过：由28个成员国组成，约5亿人。"（**英国**2020年1月31日**脱欧**后为27个。）
  - "欧盟有点像一个国家，但又不是：它是一个**联盟**，不是联邦或共和国，即每个成员国有权退出，就像我们现在在英国看到的那样，但很复杂，那是另一回事。"
  - 尽管如此，他们有欧盟护照、欧盟内部市场、欧盟标准法律等，还有自己的货币联盟：**欧元**，19个成员国在用（2023年克罗地亚、2026年保加利亚加入后为21个）。
- **欧洲其他组织**：在整个欧洲还有很多其他小组织，"我快速列一下，每个一句话总结"：
  - **申根区**：基本是欧盟加一些不在欧盟但入境不需护照的地方。如果你是欧盟公民，在这些地区工作生活很容易。塞浦路斯、罗马尼亚、克罗地亚和保加利亚虽是欧盟成员，仍在待定状态（**克罗地亚**2023年、**罗马尼亚和保加利亚**2025年全面加入；塞浦路斯仍未加入）。
  - **欧洲经济区（EEA）**：基本是欧盟加上那些被允许采用与欧盟相同经济政策的国家（冰岛、列支敦士登、挪威）。
  - **欧洲自由贸易联盟（EFTA）**：差不多一样，只是一个由四个不属于欧盟的特殊国家（冰岛、列支敦士登、挪威、瑞士）组成的自由贸易区。
  - 还有其他小区域组织：**北欧理事会**、**波罗的海**集团、**维谢格拉德集团**、**比荷卢**。"基本上这些组织都只是邻国一起出去玩、开派对的借口，至少我这么看。"
- **阿拉伯国家联盟**：
  - 总部埃及**开罗**。基本是所有说阿拉伯语或以阿拉伯语为官方语言的国家，不管居民是否认同自己是阿拉伯人。"这就是为什么像**索马里**和**科摩罗**是成员，但他们说'我们不是阿拉伯人'，更别让**摩洛哥人**开口了。"
  - **叙利亚**曾是成员，但2011年被暂停，"我真的不用多解释"（2023年恢复）。
  - 记住这不是一个穆斯林专属的联盟，很多阿拉伯人或说阿拉伯语的人不是穆斯林，但理事会成员大多是穆斯林国家。
- **海湾合作委员会（GCC）**：
  - 常被称为海湾共同体，总部沙特**利雅得**。这是另一个关税同盟和贸易集团，海合会公民基本可以在各成员国间自由流动，"除了卡塔尔，但那有点不同"。
  - 基本是波斯湾沿岸除**伊拉克**（和伊朗）外的所有国家，成立初衷基本是为了**制衡伊朗**在中东的影响。长话短说，他们甚至有自己的联合军队：**半岛之盾部队**。
  - 2017年他们与**卡塔尔**断绝外交关系，局势很紧张，"我不深入了，基本上2019年局势开始稍微降温，卡塔尔正慢慢回到海合会"（2021年1月**欧拉宣言**正式结束断交）。
- **南亚区域合作联盟（SAARC）**：
  - 总部**加德满都**，8个国家。这是少数**印度和巴基斯坦**都同意参加的多边组织之一。
  - 2006年他们终于启动了**南亚自由贸易区**，让16亿人可以进行经济往来，大大降低了商品关税，"很多人很高兴"。（2016年后因印巴紧张，峰会长期停摆。）
- **东盟（ASEAN）**：
  - 总部**雅加达**，是亚太事务的核心联盟，由10国组成（2025年**东帝汶**加入后为11国），2个观察员（巴布亚新几内亚、东帝汶）。
  - 这个组织在该地区有很强的影响力，是自由贸易区、**无核武器区**，还管理金融一体化、粮食安全、旅游、环境等问题。
- **上海合作组织（SCO）**：
  - 覆盖亚欧大陆约3/5和世界约一半人口，2001年由五个创始国创立："中国、哈萨克斯坦、吉尔吉斯斯坦、俄罗斯和塔吉克斯坦，偏偏是**塔吉克斯坦**？"（加上乌兹别克斯坦为六国。）后来加入了巴基斯坦，以及印度和巴基斯坦（2017年）。（**伊朗**2023年、**白俄罗斯**2024年加入。）
  - 它绝对不是关税同盟或自由贸易区，但在很多其他领域开展活动，比如安全问题，尤其是**反恐**和**禁毒**，也促进经济和文化合作等。
- **非洲**：
  - **西非国家经济共同体（ECOWAS）**：
    - 另一个贸易集团和关税同盟，也有一支**维和**部队，有法院、议会、发展投资银行等。
    - 有15个西非成员国，其中9个大多讲法语，使用**西非法郎**（原话如此，实为8个西非经济货币联盟国家）。讲英语的国家正在考虑使用自己的货币 **Eco**。
    - （**马里、布基纳法索和尼日尔**2025年1月正式退出，另组"**萨赫勒国家联盟**"。）
  - **中非国家经济共同体（ECCAS）**："作为对西共体的回应"，基本同样的模式。由11个大多讲法语的中非国家组成，其中6个使用**中非法郎**，主要目标是维持中非市场和地区和平，"尽其所能"。
  - **南部非洲发展共同体（SADC）**："作为对那个的回应"，基本是16个国家组成的自由贸易区，是南部的贸易集团。
  - **南部非洲关税同盟（SACU）**：在南部，基本是六个国家，人们可以比较自由地流动、彼此投资（原话如此，实为5国：南非、博茨瓦纳、莱索托、纳米比亚、斯威士兰）。"最南边这几个是最发达的，在整个发展共同体里算是得到了最好的待遇。"
  - **政府间发展组织（IGAD）**："作为对那个的回应"，同样的模式，基本就是东非，由8个国家组成的贸易集团，尽力合作，共享共同的文化和经济色彩。
