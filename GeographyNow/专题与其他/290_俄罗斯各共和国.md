# 俄罗斯各共和国解说（RUSSIAN REPUBLICS Explained）

> Geography Now 视频 #290 · 发布于 2018-09-21 · [观看视频](https://www.youtube.com/watch?v=_OBUVipjUzk) · 专题（填充周）
> **说明**：片中按俄罗斯的说法列了22个共和国，其中**克里米亚**的归属在国际上有争议（多数国家视为乌克兰领土），主持人也专门说明了这一点。片中把车臣、达吉斯坦等地的冲突也一并简述，以下按原话整理。

## 开场
- **赞助**：这期由网站建设平台 **Squarespace** 赞助。
- **选题**：上次讲了印度各邦，问观众下一个想看哪个国家的行政区，很多人说俄罗斯。问题是俄罗斯联邦有85个联邦主体，分五类（2014年后的俄方口径）。"Geography Now 没时间讲85个东西，但有时间讲其中一类：**共和国**。"
- **什么是共和国**："俄罗斯其实非常多元，住着很多不同的民族，不只是俄罗斯人。共和国就像非俄罗斯族的民族飞地，有自己的行政层级，有权确立自己的语言和宪法，其他主体没有这些权利。"如今有22个。

## 22 个共和国
- **阿迪格共和国**（首府迈科普）：
  - 代表民族是**阿迪格人**，切尔克斯十二部落之一，也是以切尔克斯人为代表民族的三个联邦主体之一。他们甚至用**切尔克斯旗**作为共和国旗。
  - 文化上是山民，有一系列传统习俗，爱拉一种像匕首的小提琴，还有踮脚跳的传统舞蹈（"看着有点疼"），以及夹奶酪的饼。
  - 有古老的**石棚墓（dolmen）**，"没人确切知道是什么，有人说是坟墓"。
  - 按传统，新郎不能见岳父母（"此处插入冒犯性笑话"）。
- **阿尔泰共和国**（首府戈尔诺-阿尔泰斯克）：
  - 代表民族是**阿尔泰人**，属突厥语族，来自十个氏族。
  - 这里有一处联合国教科文组织世界遗产，**乌科克高原**有奇特的石结构，被认为是墓葬，"有人说是能引导宇宙能量的磁性装置，对，这里有很多新世纪旅游"。
  - 也是发现在永久冻土里保存的"**西伯利亚冰少女**"的地方。
- **巴什科尔托斯坦共和国**（首府乌法）：
  - 代表民族是**巴什基尔人**，人口最多的共和国，是1917年建立的第一个民族自治区。他们来自**乌拉尔山**，旗上有 **kurai 花**，七片花瓣代表孕育巴什基尔人的七个氏族。
  - 音乐很重要，他们用 kurai 植物的芦苇做木笛。首府有一座献给"这个人"（民族英雄**萨拉瓦特·尤拉耶夫**）的巨大纪念碑。
- **布里亚特共和国**（首府乌兰乌德）：
  - 代表民族约占人口30%的**布里亚特人**，属蒙古语族，与蒙古人和卡尔梅克人有亲缘关系。
  - 共和国紧邻俄罗斯最大、世界最深的湖**贝加尔湖**，所以不允许大规模工业化，以免污染湖泊。
  - 文化上很有意思，把**佛教和萨满教**融合在一起，有骨卜等独特传统。还有很棒的温泉，据说能治百病。
- **车臣共和国**（首府格罗兹尼）：
  - "这个你大概在新闻里听过几次。"代表民族**车臣人**约占95%，因为伊斯兰教，是俄罗斯饮酒最少的地区。
  - 历史上，俄罗斯进来时**斯大林**起了疑心，把很多人流放到哈萨克斯坦，后来又让他们回来。90年代他们试图宣布独立，俄罗斯说"不行"，随后爆发了**车臣战争**，有一系列分离运动和恐怖袭击。
  - 如今已经平息，但分离活动仍有残余，"像有人按下按钮就会点燃，现在算是僵持。人们只想正常过日子"。
  - "其实那里风景很美，如果你是那种'争议地区游客'，可以放进愿望清单。"
- **楚瓦什共和国**（首府切博克萨雷）：
  - 代表民族约占2/3人口的**楚瓦什人**，被称为"银色之民"。他们像突厥语族里奇怪的"外人"表亲，因为楚瓦什语最孤立，其他突厥语使用者很难听懂，"有点像突厥语里的冰岛语"。
  - 这里最有名的是**啤酒**，人人都知道楚瓦什酿啤酒，很多家庭自酿，还加自己的秘密配料，配着欢快的歌舞。
- **克里米亚共和国**（首府辛菲罗波尔，另有联邦直辖市塞瓦斯托波尔）：
  - "准备好，这个争议很大。乌克兰人你们不会喜欢听，但我得讲。"代表民族是**克里米亚鞑靼人**，只占约12%。他们以前是多数，但苏联时期被流放到乌兹别克斯坦，后来有些人才被允许回来。如今多数人口是俄罗斯人。
  - 这是如今俄罗斯和乌克兰最大的争议区。这片地区以前完全在乌克兰管辖下，2014年一批亲俄分离分子和俄罗斯军队介入接管。世界上多数国家**不承认**它是俄罗斯的一部分，但它实际在俄罗斯管辖下运作。
  - 它的地理位置很有利，可以通往黑海，再到地中海，"争议的温床"。这里也有古希腊遗址。
- **达吉斯坦共和国**（首府马哈奇卡拉）：
  - "**高加索之门**。"代表民族不止一个，有约10个主要民族，最大的是高加索的**阿瓦尔人**、**达尔金人**，还有突厥语的库梅克人和阿塞拜疆人。总共有100多个民族、30多种语言，是全俄罗斯民族最多元的地区，约80%认同穆斯林。
  - 有美丽的山、森林和要塞。来这里你一定会看到 **burka 毡斗篷**（"不是罩袍 burqa"）。人们爱持匕首跳舞。
  - 2008和2012年，和车臣一样有一波游击战，俄罗斯政府介入，"有点乱"。
- **印古什共和国**（首府马加斯）：
  - 俄罗斯最小的联邦主体，代表民族**印古什人**，和车臣人很像，像车臣人的弟弟，语言几乎一样，大多是穆斯林。
  - 二战时斯大林把很多人流放到哈萨克斯坦，回来时发现很多**奥塞梯人**占了他们认为是自己的土地，引发内部冲突（1992年**东普里戈罗德尼冲突**）。
  - 文化上，很多人不太清楚自己历史的全貌，因为很大程度上依赖口传和歌曲。
  - 提醒：这大概是全俄罗斯最穷的地区之一，去的话会有很多安检站。"如果你是男人，不建议留胡子，可能被误认为印古什叛军。你们见过我留胡子，我大概没事。"
- **卡巴尔达-巴尔卡尔共和国**（首府纳尔奇克）：
  - 两大民族占约70%：**卡巴尔达人**是切尔克斯人，**巴尔卡尔人**是钦察突厥人。卡巴尔达人是切尔克斯十二部落中最大的。
  - 虽然多数人认同穆斯林，仍有约12%保留传统的 **Habze** 信仰，涉及很多自然和神灵。
  - 这里有美丽的峡谷和山丘，还有全俄罗斯和欧洲（如果你把它算欧洲的话）最高峰**厄尔布鲁士山**。人们以运动著称，"这个人"为俄罗斯赢得了里约奥运会第一枚金牌（柔道运动员 **Beslan Mudranov**）。
- **卡尔梅克共和国**（首府埃利斯塔）：
  - 代表民族约占60%的**卡尔梅克人**，"大概是全俄罗斯最奇特的人口现象"：卡尔梅克人是全世界**最西边的佛教群体**，也是**欧洲唯一一个佛教占多数的地区**，首府埃利斯塔到处可见传统佛寺。
  - 按传统，他们的祖先**卫拉特人**从中亚迁来寻找更好的土地，或者逃离蒙古部落，"没人确切知道"。后来俄罗斯和他们达成很多协议，然后流放他们（1943年），又让他们回来。
- **卡拉恰伊-切尔克斯共和国**（首府切尔克斯克）：和卡巴尔达-巴尔卡尔一样有两大群体：突厥语的**卡拉恰伊人**和切尔克斯人。部分人仍保留古老的切尔克斯宗教。人们爱**骑马**，男孩9岁时有个成人仪式：要从父亲或祖父那里得到一根马鞭，用它骑马。
- **卡累利阿共和国**（首府彼得罗扎沃茨克）：
  - 代表民族**卡累利阿人**，是代表民族比例最低的共和国，不到10%。卡累利阿人是世上仅存的少数乌拉尔语族之一，是**芬兰人**的表亲，语言很相似，有人说只是芬兰语的方言。
  - 不幸的是，除非出现复兴，卡累利阿语和文化的前景有点黯淡，正在消亡。
  - 卡累利阿人有自己的旗。他们以一种很酷的蛋馅饼闻名（**卡累利阿派**），"真好吃"。
- **哈卡斯共和国**（首府阿巴坎）：代表民族**哈卡斯人**，多数学者认为他们和吉尔吉斯斯坦的**吉尔吉斯人**有亲缘关系。很酷的是这里在古代是很多人经过的十字路口，所以被称为"**西伯利亚的考古圣地**"：有大量古代遗址，比如石柱、方尖碑、废城、要塞、岩画，还有一座七层楼高的古冢（**萨拉拜古冢**）。
- **科米共和国**（首府瑟克特夫卡尔，"我已经不知道怎么念了"）：
  - 代表民族约占1/4的**科米人**。科米像**乌拉尔山**的首府，提供分界山脉的一些最好的旅游：有**科米原始森林**（世界遗产）和这座国家公园，很美。
  - 历史上这里有俄罗斯史上最残酷的一些**古拉格**，"但森林很好"。他们有自己的食物和基于基督教之前萨满教的传统，至今仍保留一些。
- **马里埃尔共和国**（首府约什卡尔奥拉）：
  - 代表民族**马里人**，在伏尔加地区，被称为"**欧洲最后的异教徒**"。他们确实保留了很多基督教之前的异教传统，"有点像基督教传入前俄罗斯的样子"。
  - 一半女人会弹**古斯里琴**。他们常举行全马里的祈祷仪式，全社区聚在一起，带来很多食物，把动物的骨、皮和内脏献给火。
- **莫尔多瓦共和国**（首府萨兰斯克）：代表民族**莫尔多瓦人**。这里地势平坦，但他们爱越野滑雪。他们非常擅长**木雕**，常能看到像小木屋的传统莫尔多瓦房屋，木头打磨得很光滑。主持人说他们有"可以说"全俄罗斯最有名的木偶剧院。
- **北奥塞梯-阿兰共和国**（首府弗拉季高加索）：
  - 代表民族**奥塞梯人**，是唯一在俄罗斯有自己共和国的**伊朗语族**民族，祖先来自伊朗（**阿兰人**），"但他们大多是基督徒"。
  - 历史上这里是**丝绸之路**的一部分，人们靠贸易赚了很多钱。如今矿产和温泉疗养地很多。
  - 还有**南奥塞梯**的争议，格鲁吉亚那集讲过：国际上承认它是格鲁吉亚的一部分，但自2008年俄格战争后，行政上算是归俄罗斯管辖。从格鲁吉亚那边进入其实需要护照。
- **萨哈（雅库特）共和国**：
  - 代表民族**雅库特人**，"是俄罗斯最像东亚人的人"。他们坚守传统，有很多传统服装和食物，爱表演马戏，爱马，夏天有个大家各展所长的节日（**Yhyakh** 夏至节）。
  - 这里有大量**钻石**开采。首府**雅库茨克**是世界上第二冷的大城市（原话如此，常被称为最冷的大城市）。
- **鞑靼斯坦共和国**（首府喀山）：
  - 代表民族约占一半的**鞑靼人**，是巴什科尔托斯坦的兄弟。在俄罗斯教授的第二语言里，**鞑靼语**是最普遍的之一。
  - 很久以前**伏尔加保加尔人**和钦察突厥人混合，就有了鞑靼人。如今这里是全俄罗斯经济最发达的地区之一，石油很多，有三处世界遗产。
  - 这里有点像东正教和伊斯兰教的混合，甚至建了一座"**万教寺**"。
- **图瓦共和国**（首府克孜勒）：
  - 代表民族**图瓦人**，"很奇怪，他们像蒙古人的表亲，却说突厥语"。他们曾是蒙古的一部分（原话如此，历史上曾是独立的唐努图瓦），传统习俗和蒙古人很像。
  - 这是少数还能看到草原游牧生活传统的地方。和蒙古人一样，他们有自己的**呼麦**，用喉咙同时发出两个音，听起来有点诡异。也和蒙古人一样，佛教徒明显占多数。"佛教俄罗斯人：卡尔梅克、布里亚特、图瓦。"
- **乌德穆尔特共和国**（首府伊热夫斯克）：
  - 代表民族约占30%的**乌德穆尔特人**，被称为"**草地之民**"，是全俄罗斯**红发**比例最高的民族之一，甚至有红发节。他们有自己的民族史诗，用很多弦乐器和木制乐器演奏。
  - "还记得国旗日那位观众去了乌德穆尔特吗？她寄来冰箱贴，说她是芬兰人，能听懂一点，因为他们算表亲。我觉得芬兰人、爱沙尼亚人，甚至匈牙利人可能都会对这些地区感兴趣，他们技术上是你们的远亲。"

## 结尾
"每个共和国都有自己的小故事，在俄罗斯历史里扮演过自己的角色。那是个很酷的地方，我很想去旅行、写博客。"顺势推荐 Squarespace 建站。
