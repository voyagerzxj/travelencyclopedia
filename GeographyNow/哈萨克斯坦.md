# 哈萨克斯坦（Kazakhstan）

> Geography Now 视频 #220 · 发布于 2017-11-15 · [观看视频](https://www.youtube.com/watch?v=BElOyEjTujk)
> 开场："不，我不会模仿波拉特，好吗？那部电影里一个哈萨克人都没有。哈萨克斯坦部分是在罗马尼亚的一个吉卜赛村庄拍的，萨沙·拜伦·科恩一半时间说的是希伯来语。不过它确实让哈萨克斯坦的旅游业涨了十倍。"这是节目讲的第一个中亚国家（"阿富汗不算吗？""对对，随便。"）。主持人说哈萨克斯坦以一种独特的方式把欧洲和东亚融合在一起，看人就知道："像亚洲人，又不太确定，因为有些人有白人特征。我懂你，哈萨克斯坦，我这辈子一直被这么看。"

## 政治地理
- **欧亚之桥**："如果把中东算亚洲，土耳其是欧亚之桥；而哈萨克斯坦是欧洲和东亚之间的桥。"
- **位置**：中亚，与5国接壤。离蒙古**只差一点**，中间隔着一条约20英里宽的走廊。西北临**里海**，唯一的海港**阿克套**在那里。
- **面积**：
  - 世界最大的内陆国，世界第九大国家。主持人说"近100万平方公里"，实际约272万平方公里。
  - 国土东西跨度大约相当于伦敦到伊斯坦布尔。
  - 欧洲最长的公路 **E40** 从法国加来一直延伸到哈萨克斯坦的里德尔，约8000公里（原话说5300多英里）。俄罗斯："呵呵，可爱。"
- **行政区**：14个州，首都**阿斯塔纳**在阿克莫拉州（2019年改名努尔苏丹，2022年又改回阿斯塔纳）。
- **城市与机场**：南部的**阿拉木图**其实是最大城市，**奇姆肯特**排第三。三座城市都有哈萨克斯坦最繁忙的机场。
- **苏联遗留的边界问题**：
  - 主持人演戈尔巴乔夫："大家好，我是戈尔巴乔夫，你们这些加盟共和国都从苏联解放了。苏联不再是苏联，就是俄罗斯。哦，现在是1990年。"各"斯坦"："可我们社区都混在一起，边界怎么画？"戈尔巴乔夫："你们想要的，你们自己想办法。""吉尔吉斯斯坦那集会很好玩，我保证。"
  - **里海岛屿**：与俄罗斯争沼泽地 **Ukatnyy 岛**，以及 Zhestky 和小 Zhemchuzhnyy 沙洲，这一带以海上产油区闻名。
  - **复兴岛**：与乌兹别克斯坦争议，因咸海干涸，如今已成半岛。
- **拜科努尔航天发射场**：
  - 最奇特的领土特例：世界第一颗人造卫星**斯普特尼克**和**加加林**的首次载人轨道飞行都在这里发射。
  - 它租给俄罗斯到2050年，如今要去的话需要俄罗斯签证，除非运气好约到导览。
  - 主持人演1991年：
    - 俄罗斯："好了哈萨克斯坦，你现在是自己的国家了，自由了。"
    - 哈萨克斯坦："哇！我有自己的地盘、里海、矿山、矿田、草原……哦看，一个航天站！"
    - 俄罗斯："哒哒哒！那个还是我的！"
    - 哈萨克斯坦："好吧，但别忘了你在东边搞的那些核试验，那里现在是地球上辐射最强的地方之一。"
- **塞米巴拉金斯克**：苏联的核试验场。"去查吧！他们建的时候没想到哈萨克斯坦有一天会独立。"
- **古迹与景点**：哈萨克斯坦有2.7万多处古迹。
  - 独立纪念碑、**和平与和谐金字塔**。
  - 有"**金人**"的伊塞克古墓。
  - 联盟11号纪念碑。
  - 世界最高的帐篷**可汗之帐（Khan Shatyr）**、**巴伊杰列克观景塔**。
  - 世界最大的高山滑冰场**麦迪奥**、升天大教堂、阿雷斯坦巴布陵墓。
  - 哈萨克斯坦国家博物馆、民族乐器博物馆、喷泉马戏团。
  - **科克托别山**休闲中心：有游乐设施，还有一座披头士雕像。
  - 努尔阿斯塔纳清真寺、Mangilik El 凯旋门。
  - "但别去塞米巴拉金斯克，那里比切尔诺贝利还糟。"

## 自然地理
- **比喻**："哈萨克斯坦的风景像蒙古的平行宇宙《阴阳魔界》版：有点像，但又有点不对劲。"
- **地形**：总体平坦，有大片草原和平原，比如**里海低地**、图尔盖谷地和哈萨克丘陵，构成国土的大部分。
- **山**：东部和东南部是**阿尔泰山**和**天山**，最高峰**汗腾格里峰**，"又是中亚版的罗赖马山"，中、哈、吉三国的交界点。"我不知道中国为什么还要分这一块，你们已经有一半珠峰了，干嘛还要别国最高峰的一部分？""我知道，对吧？"
- **河湖**：
  - 最长的河**额尔齐斯河**流经东北部，与俄罗斯和中国共享，"危险地靠近塞米巴拉金斯克的辐射尘"。
  - 不过**伊希姆河**更重要，因为它流经首都阿斯塔纳。
  - 最大的湖**巴尔喀什湖**很奇特：西半部是淡水，东半部是咸水。
- **奇特地貌**：
  - "**球之谷**"：满是直径约3到4米的奇特球形风化巨石（主持人笑场）。
  - 奇怪的水下森林（**卡因迪湖**）、**唐巴勒峡谷**（岩画）、**恰伦峡谷**。
  - 最著名的自然地标：正在干涸的**咸海**。苏联时期把水引走，如今是一片末世般的景象：锈迹斑斑的废弃船只躺在干草原上，远处双峰驼静静吃草。"如果你在另类摇滚乐队，这里是拍专辑封面的完美地点。"
- **资源**：
  - 元素周期表上约100种元素都能在哈萨克斯坦开采到。
  - 石油储量世界第12，天然气储量前20，大多集中在面积约970平方英里的**田吉兹油田**，世界最大的油田之一，所以最大的出口品是石油。
  - 这让哈萨克斯坦成为中亚最大的经济体，约占整个地区 GDP 的60%。
- **动物**：
  - 野生动物很多：田鼠、苍鹭、蝙蝠、侏鸬鹚、狼、狐狸、白鼬、虎鼬、**高鼻羚羊**。
  - 两种国家动物：**雪豹**和**金雕（草原雕）**。
- **马**：
  - 马大概是最重要的动物，据说马最早是在哈萨克斯坦被驯化的。乌克兰和俄罗斯："嗯，有争议。"
  - 马也关系到饮食。有个笑话说哈萨克人是世界第二大吃肉的群体，第一是狼。格陵兰："哈，接受挑战。"
  - 国菜 **beshbarmak**，字面意思是"**五指**"，因为要用手吃：面条上铺着马肉。"对，他们吃马。"但规矩是：**不吃自己骑的马**。蒙古："别抄我！"
- **苹果的故乡**：据说苹果起源于哈萨克斯坦。**阿拉木图**这个名字意思就是"**苹果之地**"，哈萨克斯坦各地的森林里能找到很多野苹果树。
- **经济**：2002年成为第一个获得投资级评级的前苏联国家，还清了欠国际货币基金组织的全部债务。"但所有这些前进也带着一点背景故事和一丝争议。"

## 人口
- "我个人很喜欢见哈萨克族人，因为感觉他们像是我出生时失散的兄弟姐妹，太奇怪了，就是那种亚洲和欧洲的美丽混合。"
- **基本情况**：
  - 约1810万人，每平方公里约6人。
  - 约67%是哈萨克族，约20%是俄罗斯人，其余是其他族群，大多是突厥语族，比如乌兹别克人、维吾尔人，还有车臣人、乌克兰人、鞑靼人、波兰人等。
  - 货币**坚戈**，C 型插座，靠右行驶。
- **哈萨克人是谁**：
  - 如今这个问题比一千年前难回答得多。最简单地说，哈萨克人属于**突厥语族群**，"不是土耳其的，是突厥的，有区别"，与亚洲和欧洲很多国家和民族有相同的语言结构。
  - 主持人推荐了 YouTube 频道 Guiloteam 主持人 Aissulu 讲这个的视频。
  - 这形成了一种独特的人群，"看起来像一整个国家的混血儿"，有点像巴西的**帕尔多人**。
- **语言**：
  - 哈萨克斯坦其实处于文化十字路口：说**俄语**的人比说本民族**哈萨克语**的还多。（"我懂你。"）
  - 自独立起一直担任总统的**纳扎尔巴耶夫**宣布，未来几年哈萨克语将从**西里尔字母改为拉丁字母**，有人认为这是一种巧妙的"哈萨克化"举措。纳扎尔巴耶夫也有争议，比如他在被指控侵犯人权后于2015年提前举行大选。（他2019年辞去总统职务。）
  - 作为突厥语国家，哈萨克人能大致听懂其他突厥语邻居的话，这些民族从俄罗斯东北的北极冻原一直分布到黑海边的土耳其，以及摩尔多瓦奇特自治区里的加告兹人。"摩尔多瓦那集会很好玩，那是个人们不在乎一切都烧成灰、照样跳舞的地方。"
- **历史速通**：
  - 斯基泰人；说突厥语的蒙古部落到来；匈人入侵。
  - 阿拉伯人；喀喇汗王朝的突厥人带来伊斯兰教；各部落势力争夺控制权；契丹人入侵。
  - **帖木儿**建立帝国；哈萨克人从乌兹别克汗国分离出来；准噶尔人入侵。
  - 俄罗斯人来帮忙，然后俄罗斯人基本接管统治；**克涅萨尔汗**反抗俄国失败。
  - 大量俄罗斯人和乌克兰人涌入工作；一战时哈萨克人反抗征兵。
  - 成为苏联的自治共和国，受俄罗斯影响几十年；1991年独立。
  - 首都迁移；大量哈萨克人回迁、俄罗斯族迁出，哈萨克人重新成为本国多数民族。
  - 纳扎尔巴耶夫成为唯一的总统；一堆油气管道争议。"就到了今天。"
- **宗教**：
  - 约64%至少名义上认同穆斯林。但1990年纳扎尔巴耶夫为哈萨克穆斯林设立了独立的穆夫提管理机构，禁止宗教政党，让哈萨克斯坦脱离中亚穆斯林委员会的管辖，宣布哈萨克斯坦为世俗国家，尽管政府对所有宗教团体都严格控制。
  - 这让哈萨克斯坦成为唯一在宪法中不给伊斯兰教特殊地位的中亚国家。除了某些有清真寺的地方，你几乎感觉不到，尤其在繁华的城市。
  - 这是因为哈萨克斯坦的文化更多源自突厥和蒙古，而不是刻板印象中的中东阿拉伯穆斯林文化。他们是游牧民族，农村甚至还有人住**毡房**。蒙古："天哪，又来！"
- **节日与传统**：
  - 节庆时能看到人们穿传统服装，演奏传统草原民乐。
  - 他们过三个新年：公历新年、春分的**纳吾鲁孜节**，以及儒略历新年。
  - 有很多和马有关的节日和游戏，比如骑马捡手帕，还有"**姑娘追**"：骑马去抢女人，抢不到就让她用鞭子抽你。
- **体育**：哈萨克人擅长举重、自行车和冰球。
- **名人**（"至少是你们哈萨克观众告诉我的，大部分我完全不知道是谁"）：
  - 自行车手**维诺库罗夫**、拳击手**根纳季·戈洛夫金**、花样滑冰运动员**丹尼斯·谭**。
  - 诗人**阿拜**、生物学家 Ken Alibek、诗人**奥尔扎斯·苏莱曼诺夫**、干细胞科学家 Shoukhrat Mitalipov 等。
- "基本上，这是一片东亚欧洲混血、名义上信伊斯兰、说俄语、爱骑马也爱吃马的人的土地，听起来是能一起玩的人。"

## 朋友圈（外交关系）
- **中亚老大哥**：哈萨克斯坦像中亚的"老大哥"，要和其他前苏联加盟共和国打交道，通常得先从这里开始。
- **中亚邻居**：总体和突厥语、俄语国家相处不错，但中亚有点像巴尔干，"一个有点不正常的家庭"：
  - **土库曼斯坦**像自我孤立的愤怒兄弟。
  - **乌兹别克斯坦**像和所有兄弟吵架的愤怒兄弟。
  - **吉尔吉斯斯坦**像他们爱的小弟弟，但总找他们要钱。
  - **塔吉克斯坦**像说波斯语族语言的远房表亲。
- **土耳其、蒙古、韩国**：像远方的亲密朋友，有共同的突厥和蒙古人种的历史文化，贸易往来很好。很多韩国人似乎喜欢搬到哈萨克斯坦。
- **美国**：独立后第一个承认它的国家，一直在投资。
- **最好的朋友：俄罗斯**：他问过的大多数哈萨克人都这么说。
  - 虽然有过争议时期，但总体上两国不仅在关税同盟里关系密切（与白俄罗斯一起有自由贸易协定），几乎在所有外交层面都相处得很好。
  - 两国都说俄语，都爱看俄罗斯电视剧。虽然哈萨克斯坦想摆脱俄罗斯影响、寻找更哈萨克的身份，却忍不住保留着那些深深植根于历史中的俄罗斯元素。

## 总结
"哈萨克斯坦是一个东亚混血、爱马、以穆斯林为主、说俄语、政府有争议、却靠资源开采不断向前的国家。"最后他说了个谐音梗："Kazakh-can-stand（受得了）我们学的这些精彩知识吧？太烂了，大概是我整个系列最烂的谐音梗。"下一集：肯尼亚。国旗见 [哈萨克斯坦_国旗粉丝日](国旗粉丝日/哈萨克斯坦_国旗粉丝日.md)。
