## 笔记说明

- 指南书的笔记逐章整理，保留门票、交通、住宿和餐饮价格、开放时间、联系方式等实用信息，原文名称写在括号里。
- 同一本书有多个版本时，较旧的版本会标出与新版的差异：
  - 【本版特有】：只有这一版有的内容
  - 【中文版增写】：中译本补充的内容
  - 【20xx版…】：与其他版本对照
- 扫描版书籍经过 OCR 识别。识别残缺或拿不准的数字和名称标为 “?” 或 “OCR残”。
- 价格和交通信息以原书出版时为准，现在可能已经变化，出行前请自行核实。
